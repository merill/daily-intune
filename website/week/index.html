Week in brief

Apple DDM controls and unattended Remote Help headline Intune’s latest guidance

The strongest administrator-facing updates define Apple DDM controls, unattended Remote Help deployment requirements, Android eSIM operations, and a licensing condition for Security Copilot’s Vulnerability Remediation Agent. The practical value is in the newly specified platform scope, assignment limits, prerequisites, permissions, and tenant settings.

  • Intune · Apple
    Apple DDM app settings cover supervised iOS/iPadOS 27+ and macOS 27+

    A new Intune article documents Settings catalog controls for allowing or denying apps and binaries and for managed-app allowances on supervised devices. It also says existing iOS app-launch restrictions in the Restrictions profile must be migrated because those settings are deprecated in iOS 27.

  • Remote Help · Android
    Remote Help documents unattended Windows deployment and prerequisite ordering

    The updated deployment procedure covers Windows unattended support, including required permissions, Azure Virtual Desktop agent and bootloader prerequisites, and Win32 deployment steps. The agent must be deployed first, with the bootloader configured to depend on it; a custom Intune role with the required permission is also needed.

  • Intune · App management
    VPP tokens gain a DDM management type with assignment limits

    VPP token settings now offer Management type MDM, the default, or DDM. DDM applies to app deployment and configuration on iOS/iPadOS 18 and later, but supports only Required or Uninstall assignments; Available assignments aren't supported.

  • Intune · Android
    Intune documents Android eSIM activation and removal for corporate-owned devices

    Updated guidance covers eSIM activation and removal on supported Android Enterprise corporate-owned devices, including supported Android versions, activation-code and ICCID requirements, device-view procedures, and required permissions.

  • Security Copilot · Troubleshooting
    Vulnerability Remediation Agent guidance specifies an Intune licensing gate

    The updated Security Copilot guidance states that the agentic user must have an Intune license unless Allow admins without an Intune license is enabled under Tenant administration > Roles > Settings.

For Intune administrators

Plan the iOS 27 migration from Restrictions-profile app-launch settings and verify platform scope before using Apple DDM. For Remote Help, review custom-role permissions and preserve the agent-before-bootloader deployment dependency. Validate Android device support, Android version, activation code, and ICCID before eSIM actions. For VPP DDM, use only Required or Uninstall assignments. Teams using the Vulnerability Remediation Agent should license the agentic user or enable the named tenant setting.
