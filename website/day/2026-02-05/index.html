Day in brief

EPM guidance for AVD single-session VMs leads Intune’s February update

The meaningful content changes are concentrated in Intune release, archive, and in-development guidance: EPM support for AVD single-session VMs, a Lenovo Device Orchestration admin-center link, four protected apps, new Windows Settings Catalog policies, and broader platform-management options. A separate What's New revision changed the displayed date from February 2 to January 12, 2026, and removed the Service release 2601 section and its entries, so release-history coverage now differs across the updated pages. The period is otherwise dominated by 115 Windows Autopilot updates, mostly metadata or formatting cleanup with no stated enrollment or configuration change.

  • Intune · Fundamentals
    February guidance documents EPM for AVD single-session VMs

    The February 2, 2026 What's New update documents EPM support for AVD single-session VMs. The same entry lists a Lenovo Device Orchestration link in the admin center, four newly available protected apps, and new Windows Settings Catalog policies. No administrator action is stated.

  • Intune · Fundamentals
    The Intune archive records wider platform-management options

    The archive adds EPM wildcard matching, RugGear OEMConfig support for Android Enterprise, new iOS/iPadOS and macOS Settings Catalog settings, platform-specific device cleanup rules, and macOS ADE local-administrator configuration with Microsoft LAPS support. No task or deadline is specified.

  • Intune · Fundamentals
    In-development guidance expands filtering and offboarding scope

    The In Development page now lists Android management-mode filtering, expanded Android and iOS assignment-filter values, Device Offboarding Agent integration with admin tasks, new Apple Settings Catalog updates, EPM support for AVD single-session VMs, and a planned Lenovo Device Orchestration link.

  • Windows Autopilot · Device enrollment
    Windows Autopilot’s known-issues page marks an issue resolved

    The Windows Autopilot device preparation known-issues page is dated February 5, 2026, and marks the issue resolved in February 2026. The supplied change specifies no remediation or deadline.

  • Windows Autopilot · Device enrollment
    Autopilot reference pages receive broad metadata cleanup

    The representative Hybrid Azure AD Join Device Group edit removes the ms.collection and highpri metadata entries, matching the pattern across many Autopilot page updates. These changes are described as metadata or formatting edits and specify no enrollment-procedure or administrator-configuration change.
