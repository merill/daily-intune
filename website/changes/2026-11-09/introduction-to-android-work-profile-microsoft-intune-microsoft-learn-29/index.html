Introduction to Android work profileWork Profile - Microsoft Intune | Microsoft Learn

A work profile separates the work-related data from the personal data on your enrolled device. The work profile lives on a separate part of the device so that your personal things stay private and unaffected by work. In this article, you learn how to:

Find your work profile

OnceAfter you've set up a work profile, your organization can automatically install work apps on your device. You can access all work apps in the work profile. The work profile location varies by device manufacturer and Android version. This section describes where to find the work profile in the app drawer and on the home screen.

Note

If you're using use a custom launcher, work apps can appear in places other than the app drawer or home screen folder.

App drawer

Swipe up on the home screen or select Apps to access the app drawer. Work apps appear alongside your personal apps or withinin a Work tab in your app drawer.

Get more work apps

Open the work version of the Google Play Store to see all of the apps your organization has mademakes available to you.

Continue to use the work version of the Play Store to search for and install other apps for work. If you don't see an app you need for work, you can request it from your IT support person.

The Play Store app's appearance varies by device manufacturer and Android version, but the work version is always marked with a briefcase.

Open the Settings app and go to Work profile settings. Switch the Work profile toggle off.

Google Pixel 4 (Android 11)

To see how work profile settings appear on other Android devices, see Examples of pause in the settings app.

This image shows the pause option in the app drawer on a Google Pixel 4 (Android 11). For more information, see Pause the work profile.
