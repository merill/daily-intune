7 August 2026

Collect Device Properties

Windows

The documentation now notes that collected registry key data is accessible through existing Device Inventory permissions and may expose sensitive device configuration information.

7 August 2026

Endpoints

Windows

The endpoints documentation replaces the previous regional `lgmsape...blob.core.windows.net` entries with a larger list of `amsu...lmsas.blob.core.windows.net` endpoints.

7 August 2026

Government Service

Windows

The Remediations link now points to the deploy-remediations.md page instead of deploy-remediations.

7 August 2026

Government Service

Windows

The government service page now lists Remediations, marked “n/a.”

7 August 2026

Software Center User Guide

Windows

The page title was capitalized, and its description now states that Software Center supports installing apps, software updates, and Windows upgrades, while directing users to the required setting.

28 July 2026

Follow up to IT1431577: Recommended update KB5101684 Preview for Windows devices

Message CenterMC1441767 on mc.merill.net ↗Prevent or fix issue
Windows

The message recommends installing the Windows cumulative update KB5101684 Preview to fully remediate the issue from IT1431577. This update provides a client fix and platform improvements. Organizations should deploy this update following their usual update and validation procedures.
