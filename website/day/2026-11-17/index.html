Day in brief

Intune documents Windows Server Insider pilots as CIS audit baselines enter preview

The period’s most consequential Intune updates establish a documented, nonproduction management path for eligible Windows Server Insider Preview builds and introduce a Windows 11 CIS benchmark audit profile. Intune also adds guidance for managed Google Account authentication on Android Enterprise devices, while Remote Help documents consent-based device diagnostic sharing. Configuration Manager release notes add concrete certificate and HTTPS distribution-point failure scenarios. Most remaining updates are routine wording, formatting, navigation, and screenshot maintenance.

  • Intune · Device enrollment
    Windows Server Insider Preview gets a documented Intune pilot path

    A new end-to-end guide covers enrollment, configuration, compliance, apps, updates, verification, prerequisites, and supported server types for Windows Server Insider Preview vNext. The scenario is explicitly for testing and evaluation, and Server Core is unsupported.

  • Intune · Device security
    CIS audit profiles assess 404 Windows 11 settings without remediation

    The new audit workflow creates and assigns a CIS Microsoft Intune for Windows 11 Benchmark profile covering Level 1, Level 2, and BitLocker checks. Administrators can review and export findings; the profile assesses configuration without configuring or remediating devices.

  • Intune · Android
    Managed Google Account authentication guidance expands across Android Enterprise

    A new article explains how to require managed Google Account authentication on supported corporate-owned and personally owned Android Enterprise devices, including prerequisites, enrollment types, policy creation, and assignment steps.

  • Remote Help · Troubleshooting
    Remote Help sessions can expose consented device diagnostic reports

    Helpers can request permission to view and potentially store a sharer’s diagnostic data. After consent, both participants can view the report and the helper can refresh it; reported information includes device, hardware, network, performance, security, update, storage, and peripheral details.

  • Configuration Manager · General
    Configuration Manager documents certificate and HTTPS distribution-point failures

    Release notes describe task-sequence status-message failures after Windows PE when boot media uses CNG/KSP certificates, plus HTTP 403.7 content-download failures from PKI HTTPS distribution points. The documented responses include recreating media with a legacy CSP-backed RSA certificate and temporarily adjusting IIS client-certificate settings for diagnosis.
