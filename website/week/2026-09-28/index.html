Week in brief

Configuration Manager 2609 raises SQL prerequisites and removes legacy Asset Intelligence reporting

The week’s consequential changes center on the Configuration Manager 2609 transition: stricter SQL and ODBC prerequisites and the removal of Asset Intelligence reporting components. Intune guidance also sharpens Apple DDM and enrollment boundaries, while a new Endpoint Privilege Management article documents controlled network-setting changes for standard users. Most remaining edits involve navigation, links, menu labels, and procedural wording.

  • Configuration Manager · General
    Configuration Manager 2609 now requires newer SQL and ODBC versions

    The prerequisite guidance requires ODBC Driver 18.6.2.1 or later and SQL Server 2017 CU2 or later for Configuration Manager 2609 and later. Unsupported versions can block installation or upgrades, and the guidance identifies incompatible ODBC releases.

  • Configuration Manager · General
    Asset Intelligence reporting components are removed in Configuration Manager 2609

    Starting in version 2609, Catalog Synchronization and Inventoried Software Status are removed from the Asset Intelligence home page, and Asset Intelligence reports are removed from Monitoring > Reporting > Reports. Earlier procedures apply only to version 2603 and earlier.

  • Endpoint Privilege Management · Device security
    New EPM guidance documents controlled IPv4, IPv6, and DNS changes

    The new article describes policies that let standard Windows users change IPv4, IPv6, and DNS settings while requiring confirmation, business justification, Windows authentication, or both. Devices also need an Endpoint Privilege Management elevation settings policy enabled.

  • Intune · App management
    Intune warns that reusing a VPP token for DDM loses available assignments

    Re-uploading an existing VPP token for Declarative Device Management causes available app assignments to be lost. The guidance recommends a new Apple Business token for DDM, while MDM remains the path for available assignments and apps requiring app configuration policies.

  • Intune · Device enrollment
    Automated iOS enrollment sets a Company Portal option to No

    The Run Company Portal in Single App Mode until authentication option must be set to No and will soon be removed. The Sync with computers setting, deprecated by Apple in iOS 13, is no longer included in enrollment policies.

For Intune administrators

For Configuration Manager 2609 planning, verify SQL Server and ODBC versions and identify dependencies on Asset Intelligence reports. In Intune, avoid re-uploading existing VPP tokens for DDM, set the specified Automated Device Enrollment option to No, and use MDM for assignments or app configuration scenarios covered by the guidance. EPM administrators need an enabled elevation settings policy before delegating IPv4, IPv6, or DNS changes.
