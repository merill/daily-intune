Checklist For Installing Update 2609

26 October 2026Generally available+3 / −29 lines

In brief

The documentation now states that version 2609 became globally available for installation on October 26, 2026, replacing the early-update-ring opt-in instructions.

What Intune admins need to know

Administrators can install version 2609 without following the documented early-update-ring opt-in process.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.

Early update ring

At this time,As of October 26, 2026, version 2609 is releasedglobally available for the early update ring. To install this update, you needall customers to opt in. The version 2609 early update ring PowerShell script adds your hierarchy or standalone primary site to the early update ring.

Version 2609 opt-in script

Microsoft digitally signs the script and bundles it inside a signed self-extracting executable.

Note

The version 2609 update is only applicable to sites running version 2503 or later.

To opt in to the early update ring:

  1. Open a Windows PowerShell session as administrator.

  2. Run the EnableEarlyUpdateRing2609.ps1 script, using the following syntax:

    EnableEarlyUpdateRing2609.ps1 <SiteServer_Name> | SiteServer_IP

    Where SiteServer refers to the central administration site or standalone primary site server. For example, EnableEarlyUpdateRing2609.ps1 cmprimary01.

  3. Check for updates. For more information, see Get available updates.

The version 2609 update should now be available in the console.

Important

This script only adds your site to the early update ring for version 2609. It's not a permanent change.install.
