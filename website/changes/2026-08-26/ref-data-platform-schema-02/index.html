Ref Data Platform Schema

26 August 2026Feature update+15 / −4 lines

In brief

The schema documentation now lists Android Enterprise personally owned devices with a work profile as supported for Inventory and identifies Android support for several hardware fields. It also documents unsupported fields and the limited network fields available on these devices.

What Intune admins need to know

Administrators can use the documented inventory schema for Android BYOD devices, while accounting for the listed field limitations.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
