Month in brief

Windows MDM-only enrollment loses DNS CNAME discovery on January 15, 2027

The month’s clearest operational deadline is Intune’s January 15, 2027 end of DNS CNAME auto-discovery for Windows MDM-only enrollment: affected users will enter the Microsoft enrollment server URL manually, while existing devices and other enrollment methods are unaffected. Other high-value updates covered Windows 11 26H2 baseline profile handling, controlled IPv4, IPv6, and DNS changes through Endpoint Privilege Management, Configuration Manager 2609 CMG quota preparation, and the macOS password-rotation lockout setting. Most remaining changes involved reference, metadata, link, terminology, or procedural maintenance.

  • Intune · Device enrollment
    Windows MDM-only enrollment switches to manual server entry

    Starting January 15, 2027, Intune will end DNS CNAME auto-discovery for Windows MDM-only enrollment. Users in affected organizations must enter the Microsoft enrollment server URL manually; existing devices and other enrollment methods are unaffected.

  • Intune · General
    Windows 11 26H2 baseline guidance covers new defaults and profile handling

    Intune’s updated baseline guidance includes Settings Catalog support, new settings, updated defaults, and revised guidance. Existing security baseline profiles do not update automatically; adopting 26H2 requires creating a new profile or updating an existing one.

  • Endpoint Privilege Management · Device security
    EPM guidance details controlled IPv4, IPv6, and DNS elevation

    The new Endpoint Privilege Management article describes policies that let standard Windows users change IPv4, IPv6, and DNS settings while requiring confirmation, business justification, Windows authentication, or both. Devices need an EPM elevation settings policy enabled.

  • Configuration Manager · General
    Configuration Manager 2609 puts CMG quota checks before migration

    Upgrade guidance for CMG VM scale set migration says to identify CMGs, calculate required vCPUs, check standard Dadv6 Family and regional quotas, and request increases where needed. Insufficient quota can cause QuotaExceeded.

  • Intune · Device security
    macOS setup specifies the lockout-timer setting before rotation

    The Intune macOS setup procedure directs administrators to configure Failed Attempts Reset In Minutes in the Settings catalog before rotating the password when they need to manage the lockout timer.

For Intune administrators

Update Windows MDM-only enrollment procedures before January 15, 2027. To adopt the Windows 11 26H2 security baseline, create a new profile or update an existing one because current profiles do not update automatically. If using EPM network-setting delegation, enable the required elevation settings policy and configure the desired confirmation, justification, or authentication controls. Configuration Manager teams should check standard Dadv6 Family and regional quotas before a 2609 CMG VM scale set migration and request increases where needed. For macOS password management, configure Failed Attempts Reset In Minutes in the Settings catalog before rotating the password when the lockout timer must be managed.
