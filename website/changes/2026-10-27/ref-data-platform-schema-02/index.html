Ref Data Platform Schema

27 October 2026Doc update+144 / −2 lines

In brief

The data platform schema reference now documents AppleAccessibility properties for supervised iOS/iPadOS 16+ devices and AppleContentCache, AppleContentCacheParent, and AppleContentCachePeer properties for macOS 27+.

What Intune admins need to know

Administrators can use these documented fields to interpret accessibility settings and content-cache status, storage, and relationships in analytics data.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.

AppleAccessibility

Description: Reports accessibility settings on Apple devices.Supported platforms: iOS, iPadOS

These properties are available on supervised devices running iOS 16 or later or iPadOS 16 or later.

PropertyTypeDescriptionPlatform
BoldTextEnabledboolIndicates whether bold text is enabled.iOS, iPadOS
IncreaseContrastEnabledboolIndicates whether increased display contrast is enabled.iOS, iPadOS
ReduceMotionEnabledboolIndicates whether reduced motion is enabled.iOS, iPadOS
ReduceTransparencyEnabledboolIndicates whether reduced transparency is enabled.iOS, iPadOS
TextSizelongThe configured accessibility text-size value. Values range from 0 (smallest) to 11 (largest). A value of -1 indicates that the size is unknown or hasn't been explicitly set.iOS, iPadOS
TouchAccommodationsEnabledboolIndicates whether Touch Accommodations is enabled.iOS, iPadOS
VoiceOverEnabledboolIndicates whether the VoiceOver screen reader is enabled.iOS, iPadOS
ZoomEnabledboolIndicates whether accessibility Zoom is enabled.iOS, iPadOS

AppleContentCache

Description: Reports content caching configuration, storage usage, and service status.Supported platforms: macOS

These properties require macOS 27 or later.

PropertyTypeDescriptionPlatform
CacheServerGuidstringThe unique identifier of the content caching server.macOS
CacheStatusstringThe reported status of the content cache.macOS
FreeByteslongThe available content cache storage, in bytes.macOS
LimitByteslongThe storage limit for the content cache, in bytes.macOS
MaxCachePressureLastHourdoubleThe maximum cache pressure reported during the previous hour. Values range from 0.0 to 1.0; a lower value indicates less pressure.macOS
PersonalCacheFreeByteslongThe available personal content cache storage, in bytes.macOS
PersonalCacheLimitByteslongThe storage limit for the personal content cache, in bytes.macOS
PersonalCacheUsedByteslongThe storage used by the personal content cache, in bytes.macOS
ServiceActivatedboolIndicates whether the content caching service is activated.macOS
ServiceActiveboolIndicates whether the content caching service is currently active.macOS
ServiceCacheStatusstringThe cache status reported by the content caching service.macOS
ServicePortlongThe network port used by the content caching service.macOS
ServicePublicIpAddressstringThe public IP address reported by the content caching service.macOS
ServiceRegistrationStatuslongThe registration status code reported by the content caching service.macOS
ServiceSendingReportsboolIndicates whether the content caching service is sending reports.macOS
ServiceStartupStatusstringThe startup status of the content caching service.macOS
ServiceTetheratorStatuslongThe tethered caching status code reported by the content caching service.macOS
ServiceVersionstringThe version of the content caching service.macOS
UsedByteslongThe storage used by the content cache, in bytes.macOS
