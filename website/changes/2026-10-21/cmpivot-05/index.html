Cmpivot

21 October 2026Feature updateAction required+6 / −1 lines

In brief

CMPivot is signed with the Microsoft Code Signing PCA 2011 certificate. Configuration Manager 2603 with the update rollup and version 2609 or later automatically add the certificate to Trusted Publishers; earlier versions require manual certificate export.

What Intune admins need to know

If PowerShell is set to AllSigned, ensure devices trust the CMPivot signing certificate. Administrators on earlier Configuration Manager versions must export and trust the certificate.
