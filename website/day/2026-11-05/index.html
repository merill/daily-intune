Day in brief

Automatic Autopilot Policy now documents a 25-app selection limit

5 November was a documentation-heavy Windows Autopilot update: the Automatic Autopilot Policy page now records a 25-managed-application selection limit, while related pages sharpen device-association behavior and sovereign-cloud scope. A separate Configuration Manager article documents a CMG bulk-registration token-verification failure and points administrators to KB remediation. The remaining edits mainly refresh procedures, terminology, links, metadata, and removed warnings.

  • Windows Autopilot · Device enrollment
    Automatic Autopilot Policy raises the documented application-selection limit

    The Apps section now says up to 25 managed applications can be selected for deployment, up from 10, and adds links to Enterprise App Catalog and auto-update apps. Revisit essential-application planning against the new documented limit and linked catalog guidance.

  • Windows Autopilot · Device enrollment
    Device-association guidance distinguishes Autopilot from device preparation

    The updated page says unassociated devices run Windows Autopilot deployment, while associated devices run Windows Autopilot device preparation deployment. To run device preparation without association, it directs administrators to deregister the device from Windows Autopilot.

  • Windows Autopilot · Device enrollment
    Autopilot overview adds GCCH and DoD scope with a sovereign-cloud limitation

    The Overview page now states that device preparation supports GCCH and DoD environments, but device association isn't available in sovereign clouds. It also explains TPM-backed association, policy precedence, corporate ownership, naming, and OOBE customization. Sovereign-cloud administrators should not plan device association.

  • Configuration Manager · General
    Configuration Manager documents CMG bulk-registration token failures

    The 39169655 article now documents that bulk registration token verification can fail on the management point after installing the update rollup for non-Microsoft Entra joined devices using a CMG; other CMG communication scenarios may also be affected. Administrators in that scenario should use the referenced KB remediation.

  • Windows Autopilot · Device enrollment
    Autopilot Reset guidance revises local configuration procedures

    The refreshed article revises local Windows Autopilot Reset configuration steps using Intune, Windows Configuration Designer, and the Set up School PCs app. It also documents the full-wipe requirement for hybrid joined and Surface Hub devices, so administrators should use the revised steps when configuring local Reset.
