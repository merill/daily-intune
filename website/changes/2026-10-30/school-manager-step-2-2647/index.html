School Manager Step 2

30 October 2026Feature update+6 / −14 lines

In brief

For Apple School Manager enrollment with User Affinity, the guidance now lists Setup Assistant with modern authentication (recommended) and Company Portal, removing the legacy Setup Assistant option. Both methods support multifactor authentication and password change or reset prompts; JIT registration is recommended for iOS/iPadOS ADE with User Affinity.

What Intune admins need to know

Review user-affinity enrollment configurations and consider using Setup Assistant with modern authentication and JIT registration.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
