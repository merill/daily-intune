Plan for Change: New device page experience will become the default view

17 August 2026MC1456780 on mc.merill.net ↗Message

In brief

The new Intune single device page, offering a consolidated device management view, will become the default in the September (2609) release, replacing the legacy page. All management features remain, but admins should update documentation and familiarize themselves with the new interface beforehand.

Message Center announcement

Earlier this year, we released the new single device experience that provides a single, consolidated view for device management, making it easier to access device information, monitor activity, use management tools, and perform device actions The new single device page is turned on by default. You can use the "Preview new device toggle" to turn it off and return to the original device page.

Starting with Intune’s September (2609) release, the new device page will become the default experience for all administrators, and the previous device page experience will no longer be available.

How this will affect your organization:

Admins who navigate to Devices > All devices and select a device will automatically see the new device page experience. The legacy device page will no longer be available after this change.

All existing device management capabilities remain available. This update focuses on improving discoverability, usability, and navigation without removing existing management functionality.

What you need to do to prepare:

Update your documentation as needed. We recommend becoming familiar with the updated interface before it becomes the default view.

To preview the new experience today:

  1. In the Microsoft Intune admin center, navigate to Devices > All devices.
  2. Select a device to view device-specific information, such as device properties, device activity, tools, and reports.
