Day in brief

Client-driven compliance evaluation preview is documented for supported Windows devices

The period contained eight documentation updates and no new, removed, or Message Center items. The clearest substantive change is new Intune guidance for a client-driven compliance evaluation preview: supported Windows devices can detect certain local configuration or security-state changes and proactively request a compliance re-evaluation instead of waiting for the next scheduled check-in. The remaining meaningful updates clarify Microsoft Store regional app searching and add a US government endpoint; other edits were primarily presentation or wording changes.

  • Intune · Device security
    Windows devices can proactively request compliance re-evaluation

    Intune guidance now documents client-driven compliance evaluation as a preview for supported Windows devices. Certain local changes to device configuration, security posture, or other compliance-relevant settings can trigger a re-evaluation rather than waiting for the next scheduled check-in.

  • Intune · App management
    Microsoft Store app search now documents regional catalog selection

    The Microsoft Store app workflow states that Intune searches the United States catalog by default and directs administrators to select another region from the drop-down list when needed. The unavailable-app message is correspondingly described as applying to the selected region.

  • Intune · Fundamentals
    US government endpoint guidance adds the ECS wildcard domain

    The US government endpoint list now includes Experimentation and Configuration Service (ECS) at `*.ecs.gov.teams.microsoft.us`. This is an endpoint-documentation addition, not evidence of a product behavior change.

  • Configuration Manager · General
    Configuration Manager software-update scan flow is now an image

    The Software Updates Introduction page replaces its embedded Mermaid flowchart with an image describing how Forced and Online decisions determine whether a client contacts WSUS. The supplied diff shows a presentation change, not a change to scan behavior.
