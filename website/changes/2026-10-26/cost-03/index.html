Cost

26 October 2026Feature update+7 / −4 lines

In brief

For version 2609 and version 2603 with KB39169655, CMG tiers now use D2ads_v6, D4ads_v6, and D8ads_v6 VM sizes. Earlier versions retain the previous sizes, and existing deployments migrate automatically when the update is installed.

What Intune admins need to know

Use the new VM sizes when estimating costs for updated deployments; the Small tier remains intended for lab and proof-of-concept use.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
