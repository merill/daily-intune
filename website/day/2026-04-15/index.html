Day in brief

macOS endpoint protection template deprecated amid new Intune security guidance

This was a high-volume period, but the supplied representative diffs show that many updates were ordinary Learn maintenance: links moved into reorganized Fundamentals, RBAC, and reporting paths, alongside author metadata changes. The consequential exceptions are an explicit macOS endpoint protection template deprecation and new guidance for Defender for Endpoint onboarding, tenant-attached firewall management, Intune security posture, and add-on licensing. The April 2026 In Development Message Center item is an advance-planning notice, but supplies no feature-level details.

  • Intune · Device security
    macOS endpoint protection template is explicitly deprecated

    The new macOS reference says existing policies remain unchanged, but new policies can no longer be created with the endpoint protection template. It directs administrators to Endpoint security policies for FileVault or Firewall, or Settings catalog for FileVault, Firewall, and System Policy Control (Gatekeeper).

  • Intune · Device security
    EDR guidance separates Defender onboarding from other security controls

    The new Intune how-to covers automatic connector-based and manual deployment for Windows, macOS, and Linux. EDR policies onboard devices to Microsoft Defender for Endpoint and send security telemetry, but do not configure attack surface reduction, firewall, antivirus, threat-hunting rules, response automation, or investigation workflows. Device-configuration onboarding does not support tenant-attached devices, and overlapping policy types can create conflicts.

  • Configuration Manager · Device security
    Tenant-attached Configuration Manager devices get a dedicated firewall reference

    The new Windows Firewall (ConfigMgr) reference applies to devices managed with Configuration Manager after tenant attach is configured and an Intune Firewall policy is in place. It enumerates settings such as CRL verification, where Not configured uses the client default that disables verification; stateful FTP True or False; packet queue Disabled, Queue Inbound, or Queue Outbound; and selectable IPsec exceptions.

  • Intune · Device security
    Preview security guidance defines a recommended Intune control baseline

    The explicitly labeled Preview article recommends, where licenses are available, enforced scope tags, enrollment notifications, Windows automatic enrollment, and compliance policies for Windows, macOS, and fully managed or corporate-owned Android devices. The table lists Intune Plan 1 for these controls and Microsoft Entra ID P1 for Conditional Access with Windows automatic enrollment; more controls will be added over time.

  • Intune Suite · Fundamentals
    Intune Suite guidance clarifies add-on coverage and cloud limits

    The new add-ons guide says licenses are available at additional cost and that Intune add-ons are not supported in Sovereign clouds. Its matrix lists Endpoint Privilege Management, Enterprise App Management, Advanced Analytics, and Remote Help as standalone add-ons and Intune Suite capabilities, while Microsoft Tunnel for Mobile Application Management is listed under Intune Plan 2 and Intune Suite.
