Audit CIS Benchmarks with Microsoft Intune - Microsoft Intune | Microsoft Learn

Device security

Intune documentation now describes creating and assigning a CIS Microsoft Intune for Windows 11 Benchmark audit profile. The profile assesses 404 settings across Level 1, Level 2, and BitLocker checks without configuring or remediating devices, and supports reviewing results and exporting findings.
