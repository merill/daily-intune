Day in brief

Connected Cache HTTPS rollout ties Win32 downloads to current versions and proxy support

The period's most consequential material concerns Microsoft Connected Cache: updated guidance records Intune's regional HTTPS rollout for Win32 app content, beginning June 16, and ties support to current Connected Cache and Configuration Manager versions. Configuration Manager proxy requirements and the validation procedure were also made materially more specific. The remaining Intune edits are maintenance, including a partner-list replacement, grammatical cleanup, and archive-index changes; no new or Message Center item is supplied.

  • Configuration Manager · General
    HTTPS rollout for Win32 content now carries a Connected Cache version prerequisite

    The Connected Cache page says Intune is rolling out HTTPS for Win32 app content downloads by region starting June 16, 2026. To support the change, it specifies the latest Connected Cache version: KB33247081 for Configuration Manager versions 2409, 2503, 2509, and 2603, or Configuration Manager 2603. The page describes an in-progress rollout rather than universal availability.

  • Configuration Manager · General
    Connected Cache proxy guidance now separates newer and earlier releases

    The Proxy Server Support page now says a Configuration Manager distribution point running Connected Cache can use a proxy for internet access starting with Configuration Manager 2603 or after installing KB33247081. Earlier releases require a direct internet connection or a proxy that supports relative URIs. The revised sentence also drops the previous “unauthenticated” qualifier without defining authenticated-proxy behavior.

  • Configuration Manager · Troubleshooting
    Connected Cache validation shifts to policy targeting and elevated 64-bit PowerShell

    The troubleshooting procedure now starts with a 64-bit PowerShell window opened as administrator and requires administrators to confirm that the host is targeted by policy. If Configuration Manager or Intune has not set the policy, the supplied procedure sets DOCacheHost under HKLM:\SOFTWARE\Policies\Microsoft\Windows\DeliveryOptimization to the distribution point FQDN or IP. This replaces the prior example-led check based on downloading content, Get-DeliveryOptimizationStatus, and BytesFromCacheServer.

  • Configuration Manager · General
    Connected Cache hotfix documentation now includes Configuration Manager 2603

    The KB33247081 title, applicability statement, and update instructions now include Configuration Manager 2603 alongside 2409, 2503, and 2509. The page states that the update applies to versions 2409, 2503, 2509, or 2603. This is a documented applicability expansion, not evidence that a new hotfix was published during the period.

  • Intune · Device security
    Third-party compliance partner listing swaps Kandji for Iru

    The Intune Third Party Partners page removes the Kandji entry and Kandji Device Compliance link and adds an Iru documentation link. The supplied diff establishes a partner-list change only; it does not establish new integration availability, enrollment behavior, or a required tenant action.
