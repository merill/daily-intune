Setup Automated Ios

30 October 2026Retirement+8 / −4 lines

In brief

Intune ended support for Setup Assistant (legacy) authentication for ADE with user affinity in the October 2026 (2610) service release. Existing profiles are automatically updated to modern authentication, and the legacy option is no longer available.

What Intune admins need to know

Review affected ADE profiles and use modern authentication with just-in-time registration for new configurations. No manual migration is stated.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
