Day in brief

Configuration Manager checklists now require .NET Framework 4.8 on infrastructure

Several Configuration Manager update checklists now specify .NET Framework 4.8 for site servers, specified site systems, and the console; the clarified Update 2509 entry keeps clients at .NET 4.6.2. The period also brings a higher Windows Autopilot OOBE app limit, more precise Intune Edge Copilot policy guidance, and a changed supported-app inventory. Most remaining records are documentation maintenance, including removal of the Restore and Suspend Managed Home Screen articles and index entries.

  • Configuration Manager · General
    Configuration Manager prerequisites distinguish infrastructure from clients

    The Update 2509 checklist now lists .NET Framework 4.8 for site servers, specific site systems, and the console, while clients require .NET Framework 4.6.2. The guidance says to update .NET and restart before running setup.

  • Windows Autopilot · Device enrollment
    Windows Autopilot OOBE policies can deliver up to 25 apps

    Device preparation policies can configure up to 25 apps for delivery during OOBE in both user-driven and automatic modes, giving deployment administrators a larger app-delivery capacity.

  • Intune · App management
    Edge Copilot settings now depend on CopilotMode state

    The Manage Microsoft Edge guidance places Copilot settings in different locations when CopilotMode is on or off, adds the Copilot prompts card setting, and documents that CopilotMode defaults to true while false prevents users from enabling Copilot Mode features.

  • Intune · App management
    Microsoft Lists leaves the documented supported Intune app list

    The supported Microsoft Intune apps page no longer includes Microsoft Lists for iOS or Android. Administrators reviewing MAM coverage should no longer treat that page as listing Microsoft Lists as supported.

  • Intune · General
    Managed Home Screen remote-action guidance was removed

    The Restore Managed Home Screen and Suspend Managed Home Screen pages were deleted, and the Remote actions index no longer lists either action. The removed articles had covered supported platforms, prerequisites, admin-center steps, user experience, and API references.
