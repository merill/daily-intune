Day in brief

Office baseline DDE labels get punctuation-only cleanup in Intune guidance

This was primarily a documentation-maintenance day: all 485 recorded items were updates, with no new or removed items and no Message Center notices. The clearest content diffs affect Intune security-baseline references, where curly apostrophes were changed to straight apostrophes. Other representative updates show collection, author, or reviewer metadata changes rather than documented product behavior or availability changes.

  • Intune · Device security
    Office V2 baseline reference normalizes DDE setting-label apostrophes

    In Ref V2 Office Settings, the labels “Don’t allow Dynamic Data Exchange (DDE) server launch in Excel (User)” and “Don’t allow Dynamic Data Exchange (DDE) server lookup in Excel (User)” were changed to use “Don't.” The sentence describing profile instances created before a new baseline version also changed “you’ve” to “you've.” This is a documentation punctuation edit; the diff does not show a setting-value, baseline-version, or behavior change.

  • Intune · Device security
    Windows MDM baseline guidance receives the same apostrophe normalization

    Ref Windows Mdm Settings changes “you’ve” to “you've” in the sentence explaining that a new baseline version replaces the previous version and referring to profile instances created before its availability. No policy or profile behavior change is evidenced.
