Week in brief

Intune adds unlimited Apple VPP licensing and expands comprehensive Sync to iOS/iPadOS

Most of the supplied updates are documentation maintenance, but several have concrete operational consequences. Intune now supports unlimited-license assignments for Apple Business and Apple School Manager VPP apps on iOS/iPadOS, and its comprehensive Sync action covers Windows and iOS/iPadOS workloads including configuration policies, apps, and scripts. The week also documents a macOS password-rotation prerequisite, records CMPivot certificate-trust requirements by Configuration Manager version, and states that update 37942646 is included in the Configuration Manager 2603 update rollup.

  • Intune · General
    Apple Business and School Manager VPP apps support unlimited licenses

    Intune now supports assigning Apple Business and Apple School Manager VPP apps with unlimited licenses on iOS/iPadOS. Administrators can deploy these apps across their organizations without managing license quantities.

  • Intune · General
    Comprehensive Sync now covers Windows and iOS/iPadOS workloads

    The comprehensive Sync device action applies to Windows and iOS/iPadOS devices and synchronizes key workloads including configuration policies, apps, and scripts. Administrators can invoke it from the Intune admin center without a configuration change.

  • Intune · Device security
    macOS password rotation guidance adds a lockout-timer prerequisite

    The setup guidance now directs administrators to configure `Failed Attempts Reset In Minutes` in the Settings catalog before rotating the password when they need to manage the lockout timer.

  • Configuration Manager · General
    CMPivot certificate trust requirements are spelled out by Configuration Manager version

    CMPivot is signed with the Microsoft Code Signing PCA 2011 certificate. Configuration Manager 2603 with the update rollup and version 2609 or later automatically add the certificate to Trusted Publishers; earlier versions require manual certificate export. Devices running PowerShell with AllSigned must trust the certificate.

  • Configuration Manager · General
    Configuration Manager 2603 rollup includes update 37942646

    The update entry now states that Configuration Manager 2603 update rollup KB 39169655 includes update 37942646, so administrators who install the rollup do not need a separate out-of-band hotfix.

For Intune administrators

Administrators can deploy the covered Apple VPP apps without managing license quantities and use the Intune admin center's comprehensive Sync action for supported Windows and iOS/iPadOS devices. For macOS, configure Failed Attempts Reset In Minutes in the Settings catalog before rotating the password when managing the lockout timer. In Configuration Manager environments using PowerShell AllSigned, ensure devices trust the Microsoft Code Signing PCA 2011 certificate; earlier Configuration Manager versions require manual certificate export. Administrators installing the Configuration Manager 2603 rollup do not need to schedule a separate 37942646 out-of-band hotfix.
