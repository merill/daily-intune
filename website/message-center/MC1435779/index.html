(Update) Ending support for Setup Assistant (legacy) auth method in ADE and Apple Configurator for iOS/iPadOS and macOS

30 July 2026MC1435779 on mc.merill.net ↗Message

In brief

Intune will end support for Setup Assistant (legacy) authentication in iOS/iPadOS and macOS ADE, and Apple Configurator Setup Assistant enrollment for iOS/iPadOS devices with user device affinity with the October 2610 release. They will be replaced with Setup Assistant and Apple Configurator Company Portal enrollment, using modern authentication for improved security. Existing devices remain enrolled; profiles will auto-update, but reviewing and testing updates is recommended.

Message Center announcement

Updated July 30, 2026: We have updated the content for clarity. Thank you for your patience. 

Expected with Intune’s October (2610) service release, to help improve security and align with modern authentication standards, Intune is ending support for the Setup Assistant (legacy) authentication method for iOS/iPadOS and macOS Automated Device Enrollment (ADE) and Apple Configurator Setup Assistant enrollment for iOS/iPadOS devices with user device affinity. These legacy methods do not support multifactor authentication or Conditional Access and have been superseded by Setup Assistant with modern authentication for ADE and Apple Configurator Company Portal enrollment, which provides a more secure and seamless enrollment experience for devices enrolling with user affinity. 

How this will affect your organization:

There is no impact to existing devices, they will remain enrolled.

All existing ADE enrollment profiles with user affinity that use Setup Assistant (legacy) will be automatically updated to use Setup Assistant with modern authentication. The Setup Assistant (legacy) authentication option will be removed from the creation and edit experience for new ADE enrollment profiles.

All existing Apple Configurator enrollment profiles for iOS/iPadOS with user affinity that use Setup Assistant will be automatically updated to use Company Portal for authentication. The Setup Assistant authentication option will be removed from the creation and edit experience for new Apple Configurator enrollment profiles.

What you need to do to prepare:

Review your iOS/iPadOS and macOS enrollment profiles in the Intune admin center to understand which profiles currently use Setup Assistant (legacy) for ADE and Setup Assistant for Apple Configurator enrollment. We recommend updating your enrollment profiles to use Setup Assistant with modern authentication for ADE and Company Portal for Apple Configurator and testing these changes in your environment. If no action is taken, these profiles will be automatically updated as part of this change. 

Learn more about using Setup Assistant with modern authentication to provide the most secure and best enrollment experience for ADE devices for iOS/iPadOS and macOS in this blog: Transforming the iOS/iPadOS ADE experience in Microsoft Intune
