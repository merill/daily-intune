WithBy using Microsoft Intune, you can create a tenant-wide policy that configures use of Windows Hello for Business on devices at the time those devices enroll with Intune. This policy targets your entire organization and supports the Windows Autopilot out-of-box-experience (OOBE).

For Windows devices, use of Windows Hello for Business replaces the use of passwords with strong two-factor authentication on devices. This authentication consists of a user credential that's tied to a device and uses a biometric or PIN.

After device enrollment, or when you choose not to use the tenant-wide enrollment policy, Intune supports the following methods to manage Windows Hello on discrete groups of devices:

  • Endpoint security Account protection policy: To manage settings for Windows Hello on devices after they have enrolledenroll with Intune, use the Intune Account protection profile, which is part of endpoint security Account protection policy.
  • Security baselines: Some settings for Windows Hello can be managed by security baselines like the baselines for Microsoft Defender for Endpoint security or Security Baseline for Windows 10 and later.
  • Settings catalog: The settings from endpoint security Account protection profiles are available in the Intune settings catalog.
