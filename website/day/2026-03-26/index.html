Day in brief

Intune Data Warehouse update will reset historical data and discontinue the beta Power BI connector

The most consequential notice is an expected mid-June 2026 Intune Data Warehouse change: historical data will reset to about 30 days, surrogate keys will refresh, licensing definitions will change, and the beta Power BI connector will be discontinued. Microsoft directs administrators to move to the Intune admin center’s OData feed and back up data beforehand. The day’s other substantive Intune activity centers on settings catalog restructuring and new scenario/reference guidance, not evidence of broad new tenant functionality.

  • Intune · Endpoint analytics
    Intune Data Warehouse is slated for a mid-June infrastructure change

    The Message Center notice says historical data will reset to about 30 days, surrogate keys will refresh, licensing definitions will change, and the beta Power BI connector will be discontinued. Administrators must switch to the OData feed from the Intune admin center and back up data beforehand. This is a planned infrastructure change, not an immediate tenant behavior change.

  • Intune · Apple
    Apple settings catalog guidance maps payloads and template migration

    A new Intune Apple reference covers Apple declarative configurations and MDM payloads, links to Apple YAML requirements such as OS version, enrollment type, and supervision, and maps template settings to settings catalog equivalents. It recommends using settings catalog for new policies where possible, identifies Device features, Device restrictions, Endpoint protection, and Extensions as templates on a future migration/deprecation path, and says certificate, email, Wi-Fi, and wired-network templates should still使用

  • Intune · Windows
    New Universal Print guidance directs admins to settings catalog provisioning

    The new Windows Intune how-to says to create a settings catalog printer policy that deploys a list of registered Universal Print printers and automatically installs them on managed devices. It explicitly calls the PrintProvisioning tool and printers.csv process deprecated, and lists the required printer identifiers—Device ID, shared ID, and shared name—along with Universal Print licensing and the Policy and Profile Manager role.

  • Security Copilot · Developer
    Security Copilot inclusion in Microsoft 365 E5 enters a phased rollout

    The Message Center notice says Security Copilot will be included with Microsoft 365 E5 from April 20 through June 30, 2026, providing 400 Security Compute Units per 1,000 users and core agentic features across Microsoft security products. Additional advanced capabilities may incur extra costs, so this is a planned entitlement rollout rather than a statement that every capability is included.

  • Intune · Android
    Android settings catalog reference defines corporate-owned enrollment scope

    The new Android reference lists Android Enterprise and AOSP settings and explicitly supports COPE, COBO, COSU, AOSP corporate-owned userless/shared, and corporate-owned user-associated/single-user devices. It requires corporate-owned devices enrolled in Intune, a settings catalog policy, and at least the Policy and Profile Manager role to configure the policy. This adds reference coverage; the supplied diff does not establish a newly released Android capability.
