Day in brief

Expedite-policy guidance covers targeted Windows security updates beyond normal deferrals

Windows update servicing is the period’s substantive theme. Intune added a dedicated Expedite Policies guidance page explaining acceleration of a specific supported Windows security update beyond normal deferrals and deployment timing, including creation, assignment, monitoring, prerequisites, and eligibility; the older Expedite Quality Updates page was deleted. Related guidance now makes feature-update persistence, no-downgrade behavior, and staged or intelligent rollout prerequisites explicit. Win32 app guidance also documents PowerShell script installers, while the Windows Driver Updates page removes approval and recommended-driver instructions. Remaining title, terminology, RBAC, and metadata edits are mostly editorial.

  • Intune · Endpoint analytics
    Expedite Policies guidance details targeted security-update acceleration

    The new Intune page documents policies that accelerate a specific supported Windows security update, bypass normal deferrals and deployment timing, and cover creation, assignment, monitoring, prerequisites, and eligibility. It also calls for verifying update-ring settings, removing conflicting Group Policy settings, and installing Update Health Tools on Windows versions earlier than 24H2.

  • Intune · Device updates
    The older Expedite Quality Updates page was removed

    The former Intune page covering expedited Windows security updates, prerequisites, Update Health Tools, and policy behavior was deleted. Administrators relying on that URL will no longer find its guidance there.

  • Intune · Device updates
    Feature-update guidance clarifies persistence and no-downgrade behavior

    The updated guidance states that version-targeting policies persist until changed or removed, do not downgrade devices already on newer versions, and include the latest applicable monthly quality update. It also clarifies optional versus required updates and how multiple policies are evaluated.

  • Intune · Device updates
    Rollout Options guidance adds staged offers and intelligent-rollout prerequisites

    The updated guidance adds gradual-rollout configuration, offer-group behavior, examples, and intelligent rollout using Windows Autopatch telemetry and safeguard holds. Intelligent rollout requires enabling Windows Update for Business Cloud Processing in a settings catalog profile.

  • Intune · App management
    Win32 app guidance documents a PowerShell script installer procedure

    The workflow now covers uploading a PowerShell script instead of an install command. Scripts run in the installer context, support prerequisite and post-install actions, are limited to 50 KB, and use return codes for status. With Multi-Admin Approval, create the app first, then add or modify the script.
