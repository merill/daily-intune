Day in brief

DMZ management point guide adds offline .NET Framework 3.5 installation paths

This was a documentation-only Configuration Manager period rather than an Intune service-feature rollout. The most consequential edit strengthens the untrusted-domain or DMZ management point example with explicit .NET Framework 3.5 prerequisites and offline installation procedures. Other substantive clarification makes the deployment sequence more explicit and lists Datacenter: Azure Edition in the supported Windows Server matrix. The remaining changes are mainly rollup terminology, link, and file-list URL maintenance; no new feature, retirement, or Message Center item is evidenced.

  • Configuration Manager · General
    .NET Framework 3.5 now has explicit offline installation procedures

    The example now states that .NET Framework 3.5 is not installed by default and that its feature payload may be absent from modern Windows Server images. It provides two offline methods: PowerShell with `Install-WindowsFeature Net-Framework-Core -Source D:\sources\sxs` or Server Manager's Add Roles and Features wizard using an alternate `SxS` source path. The media must match the Windows Server version on `DMZ-MP`.

  • Configuration Manager · General
    DMZ management point deployment steps now separate prerequisites from role installation

    The procedure table now has a distinct step to install management point prerequisites on the site system server, including Windows features and SQL connectivity components, before installing the management point role on `DMZ-MP`; verification follows as a separate step. Firewall guidance is also changed to say that network traffic will normally need explicit permission.

  • Configuration Manager · Windows
    Supported Windows Server listings now explicitly include Azure Edition

    The supported operating systems reference lists Datacenter: Azure Edition alongside the existing Windows Server 2025 editions, starting with Configuration Manager version 2409, and alongside the Windows Server 2022 editions, starting with version 2107. The edit clarifies the support matrix; it does not state a new starting version or announce a product-support change.

  • Configuration Manager · General
    Configuration Manager 2509 rollup page adopts sequence-based naming

    The second 2509 update rollup page changes its title, description, and heading from “Update rollup (9141.1032)” to “Second update rollup for Microsoft Configuration Manager version 2509.” The supplied diff shows a naming clarification only, not a change to the rollup payload or availability.
