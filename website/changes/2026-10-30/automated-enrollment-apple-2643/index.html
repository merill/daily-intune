Automated Enrollment Apple

30 October 2026Retirement+5 / −9 lines

In brief

Intune ended support for Setup Assistant (legacy) authentication for ADE with user affinity in the October 2026 (2610) service release. Existing profiles are automatically updated to Setup Assistant with modern authentication, with JIT registration recommended.

What Intune admins need to know

Review enrollment configurations and expect existing legacy profiles to be updated automatically. Use modern authentication for applicable ADE scenarios.
