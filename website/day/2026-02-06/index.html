Day in brief

Apple configuration guides and Win32 silent-install limits headline Intune’s February 6 changes

New Apple guidance is the period’s clearest documentation expansion: separate articles now cover Wi-Fi, VPN, custom settings, device features, and device restrictions for iOS/iPadOS and macOS, with prerequisites and supported-scope details. More operationally, Intune guidance explicitly says Win32 installations must not require dialogs, prompts, UI input, or serviceui.exe workarounds, while the Remote Help endpoint list changes. The main Configuration Manager exception is a software update point warning about oversized synchronization selections and products or categories it cannot deploy; much of the remaining activity is link and wording consolidation.

  • Intune · Fundamentals
    Intune’s In Development page adds several planning signals

    The page now lists EPM support for AVD single-session VMs, a planned Lenovo Device Orchestration link, new Apple and Android Settings Catalog options, Device Offboarding Agent admin-task integration, and expanded managed-app assignment filters. These entries support future planning, with no required action or deadline stated.

  • Intune · Apple
    Apple Wi-Fi profiles gain a dedicated Intune configuration reference

    The new article covers iOS/iPadOS and macOS Wi-Fi profiles, including prerequisites, authentication, SSIDs, security types, proxy options, and iOS/iPadOS MAC address randomization. Administrators can use it when creating and deploying Apple Wi-Fi profiles.

  • Intune · App management
    Intune guidance states that Win32 installers must run without user interaction

    The updated guidance says Intune does not support interactive Win32 installations involving dialog boxes, prompts, UI input, or workarounds such as serviceui.exe. Review packages and commands to ensure installations run silently.

  • Intune · Fundamentals
    Remote Help endpoint guidance adds and replaces firewall destinations

    The Intune endpoints page adds `*.dm.microsoft.com` and replaces `*.trouter.skype.com` with `*.trouter.communications.svc.cloud.microsoft` in the Remote Help endpoint list. Review proxy and firewall allowlists to ensure the updated destinations are permitted.

  • Configuration Manager · General
    Software update point guidance warns against broad synchronization selections

    The page says selecting too many products or categories can reduce performance because devices scan every update in the SUSDB. It also identifies Dynamic Updates, Servicing Drivers, legacy Office and operating systems, and several category types as content Configuration Manager can’t deploy; limit synchronization to relevant, necessary selections.
