Microsoft Windows Autopatch: enhancements to update approval control and management capabilities

Message CenterMC1478956 on mc.merill.net ↗Stay informed
Compliance

Windows Autopatch enhancements, rolling out Sept 1–Oct 15, 2026, offer improved control over Windows quality, .NET Framework, and quick machine recovery updates. Features include customizable automatic/manual approvals, deferral settings, update pausing, and detailed per-device reporting for better update management.

Message CenterMC1478465 on mc.merill.net ↗Stay informed
Compliance
