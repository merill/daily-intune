Day in brief

Intune reports will omit devices inactive for 12 months or more starting late February

The period is maintenance-heavy, but it contains one clear planned behavior change: Message Center says Intune reports will omit devices inactive for 12+ months from late February. Other administrator-relevant material is guidance rather than a feature launch: Cloud PKI’s customer-managed CA replacement path, Configuration Manager HSTS warnings, a corrected Connected Cache hotfix scope, and updated Edge mobile Copilot policy guidance. Many remaining records simply normalize Apple links, dates, and wording. The removed 2603 Connected Cache pages and Apple DDM assignment-filters entry do not, by themselves, prove a product retirement or GA event.

  • Intune · Endpoint analytics
    A 12-month inactivity filter is planned for Intune reports

    Starting late February 2026, Intune will exclude devices inactive for 12+ months from reports. Reported counts may decrease to reflect active devices only. Message Center says no action is needed, but devices must check in to remain included.

  • Cloud PKI · General
    Cloud PKI guidance details the customer-managed CA replacement path

    The current expiration guidance says Microsoft cannot automatically renew or replace a Cloud PKI CA or update associated SCEP profiles. Administrators should create a replacement issuing CA with matching properties, copy its SCEP URI, and replace the old URI in every referencing SCEP certificate profile; otherwise those profiles stop issuing new certificates after expiry. Direct renewal of an existing CA is still described as coming soon.

  • Configuration Manager · General
    Configuration Manager HSTS guidance flags FSP and SUP breakage

    The communications guidance warns that HSTS requires HTTPS, is incompatible with Enhanced HTTP, and is unsupported for client communication because Configuration Manager clients do not honor HSTS headers. Enforcing it stops the HTTP-only Fallback Status Point and blocks WSUS update payloads delivered over HTTP. HTTPS must be enabled on an applicable site system before configuring HSTS.

  • Intune · App management
    Edge mobile guidance documents default-enabled Copilot chat and context access

    The updated Microsoft Edge guidance says M365 Copilot chat on iOS and Android is enabled by default and can access browsing context such as opened tabs and browsing history by default. It identifies Chat and ChatPageContext policy controls. M365 Copilot Mode currently shows suggestion prompts on the new-tab page, with default enablement planned for a future version and CopilotMode available as an MAM opt-out policy.

  • Configuration Manager · General
    Connected Cache documentation narrows hotfix scope from 2603 to 2509

    The Connected Cache hotfix reference now applies to Configuration Manager current branch 2509 rather than 2603. Its stated prerequisite range changes from versions 1910 through 2603 to versions 1910 through 2509. Verify the site branch before following the hotfix instructions; this is a documentation scope correction, not evidence of a new Connected Cache feature.
