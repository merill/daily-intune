Day in brief

Apple configuration guidance splits into focused custom, feature, restriction, VPN, and Wi-Fi references

Five new Apple-focused configuration references headline 75 changes: custom settings, device features, device restrictions, VPN, and Wi-Fi. The documentation consolidates iOS/iPadOS and macOS configuration information around clearer prerequisites and built-in-profile guidance, while Configuration Manager adds an important Software Update Point performance warning.

  • Intune · Apple
    Custom Apple settings guidance recommends built-in profiles for sensitive configuration

    The new custom-settings article describes importing iOS/iPadOS and macOS custom profiles, but directs administrators to check Settings catalog first and not to use custom profiles for sensitive Wi-Fi or authentication settings when built-in Wi-Fi and certificate profiles are available.

  • Intune · Apple
    Apple device restriction settings receive a dedicated reference

    The new reference centralizes iOS/iPadOS and macOS restriction settings, including data-transfer and app controls. It documents that certain Wi-Fi-dependent restrictions require the built-in Wi-Fi template rather than a custom profile.

  • Configuration Manager · General
    Configuration Manager warns against over-selecting WSUS products and categories

    Software Update Point guidance now warns that clients scan every update in SUSDB, whether deployed or not. It recommends synchronizing only relevant products and categories and explicitly calls out unsupported stand-alone WSUS items and legacy products to avoid.
