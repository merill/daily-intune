Week in brief

KB36495448 fixes co-managed update-source drift as Intune EPM scope is clarified

Most of the week’s 87 records are documentation maintenance—renamed headings, normalized terminology, link and example replacements, and formatting. The substantive exceptions are a new Configuration Manager client hotfix article, Connected Cache HTTPS guidance, explicit Intune Endpoint Privilege Management licensing and Windows scope, an iOS/iPadOS enrollment MFA limitation, and expanded Multi Admin Approval coverage. There are no Message Center entries and no retirement record, so the supplied evidence does not establish a new preview or general-availability launch.

  • Configuration Manager · General
    Configuration Manager documents KB36495448 for co-managed update-source drift

    The new hotfix article covers Configuration Manager 2503 with update rollup 32851084 and version 2509 when third-party updates are enabled. It describes a partial Windows Update scan-source policy in which UseUpdateClassPolicySource and SetPolicyDrivenUpdateSourceForOtherUpdates could be set while related Feature and Quality Update values were absent or removed, redirecting updates intended for Intune or Windows Update for Business to WSUS/Configuration Manager.   • Configuration Manager · General
    Connected Cache guidance describes HTTPS delivery and PKI prerequisites

    The updated hotfix article applies to Configuration Manager versions 2409, 2503, and 2509 and states that distribution point cache nodes can deliver content over HTTPS. It identifies secure delivery for Intune-managed Win32 applications and, for the first time, Microsoft Teams content; all other content types remain HTTP. HTTPS delivery requires cache nodes to present valid TLS certificates to client devices, with customers using their PKI to generate them.

  • Intune · Device security
    Endpoint security guidance makes EPM licensing and device scope explicit

    The Endpoint security page now describes Endpoint Privilege Management as allowing standard users temporary elevation for IT-approved applications, with elevation rules supporting file hashes, publisher certificates, and file paths. It explicitly states that EPM is an Intune add-on requiring an additional license, available standalone or through the Microsoft Intune Suite, and that EPM policies are available only for Windows devices. This is a documentation clarification, not evidence of a new availability event.

  • Intune · Device enrollment
    iOS/iPadOS Automated Device Enrollment warns against phishing-resistant MFA

    A new caution states that phishing-resistant MFA is currently unsupported on Setup Assistant for iOS/iPadOS. Users enrolling through Automated Device Enrollment with modern authentication must have an alternate MFA method available to complete enrollment.

  • Intune · Fundamentals
    Multi Admin Approval guidance now includes compliance and Settings Catalog policies

    The Multi Admin Approval article now lists creating and managing compliance policies and configuration policies through the Settings Catalog within its stated scope. App deployments remain covered, while app protection policies remain excluded. The record establishes a documentation scope update, not a separate preview or general-availability announcement.

For Intune administrators

Prioritize co-managed Configuration Manager estates that use third-party updates by assessing KB36495448 and its documented scan-source cleanup. If Connected Cache HTTPS delivery is relevant, prepare a valid client-trusted TLS certificate through organizational PKI. Intune administrators should verify EPM add-on licensing and Windows-only targeting, provide an alternate MFA method for modern-authentication Automated Device Enrollment on iOS/iPadOS, and review Multi Admin Approval governance for compliance and Settings Catalog policy workflows. The evidence does not support tenant action for purely editorial changes or treat these documentation updates as launch announcements.
