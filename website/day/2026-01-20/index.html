Day in brief

Managed Home Screen remote actions gain documented Android scope and permissions

The period’s most consequential Intune guidance changes clarify remote Managed Home Screen operations, tighten the documented app-protection assignment requirement, and record Windows quality-update enforcement in Enrollment Status Page guidance. The remaining updates are primarily navigation, terminology, formatting, and setup-documentation refinements.

  • Intune · General
    Restore Managed Home Screen guidance defines supported Android modes and permissions

    The updated guidance identifies Android Enterprise corporate-owned Fully Managed (COBO) and Dedicated (COSU) devices as supported, names the required permission as “Remote tasks/Restore Managed Home Screen,” and provides an updated Microsoft Graph reference for automation.

  • Intune · General
    Suspend Managed Home Screen guidance adds the supported device scope

    The documentation now specifies Android Enterprise corporate-owned Fully Managed (COBO) and Dedicated (COSU) devices, identifies the required permission, and updates the Microsoft Graph API reference for the suspend action.

  • Intune · App management
    App protection assignments explicitly require a users group

    Step 9 now directs administrators to select the users group and states inline that groups containing devices cannot be used for app protection policies.

  • Intune · Device enrollment
    Enrollment Status Page guidance records 2026-01 B quality-update enforcement

    The article now states that OS enforcement for the Install Windows quality updates Intune setting is included in the 2026-01 B quality update. Administrators managing Windows quality-update settings should account for that documented enforcement.

This period briefing was generated by AI from the tracked Microsoft Learn and Message Center changes.
