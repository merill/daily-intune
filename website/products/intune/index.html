Intune ending support for Windows MDM-only enrollment CNAME auto-discovery

Message CenterMC1509780 on mc.merill.net ↗Plan for change
Device enrollment

Starting January 15, 2027, Intune will end support for DNS CNAME auto-discovery in Windows MDM-only enrollment. Organizations using this must have users manually enter the Microsoft enrollment server URL. Existing devices and other enrollment methods remain unaffected. Update enrollment procedures accordingly.
