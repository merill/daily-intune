Week in brief

Cloud PKI expiry guidance requires issuing CA replacement and SCEP updates

The week was dominated by mechanical Learn maintenance, particularly Configuration Manager reference and navigation updates, rather than service announcements. The meaningful exceptions were a customer-managed Cloud PKI expiration procedure, a Windows Autopilot device preparation limit increase, clearer Endpoint Privilege Management child-process behavior, and refreshed Windows MAM guidance. New Cloud PKI deployment, audit, and lifecycle pages appear alongside removals of older pages with matching content, which indicates documentation reorganization rather than a documented capability retirement. No Message Center items were supplied.

  • Cloud PKI · General
    Cloud PKI expiration guidance makes CA replacement customer-managed

    The new Cloud PKI CA expiration guidance says Microsoft can't automatically update a CA or its SCEP profiles. If an issuing CA expires, profiles that reference it stop issuing new certificates, potentially causing loss of Wi-Fi, VPN, or email connectivity, resource access failures, and certificate-based authentication failures.   • Windows Autopilot · Device enrollment
    Autopilot device preparation limit increases to 25 apps

    Windows Autopilot device preparation guidance records a maximum of 25 apps, up from 10. The change applies to both user-driven and automatic modes, including all Cloud PC offerings. Administrators assigning more apps during OOBE are told to adjust deployment timeout settings to help avoid unexpected timeouts.

  • Endpoint Privilege Management · Device security
    EPM guidance exposes child-process elevation paths that bypass deny rules

    Endpoint Privilege Management guidance now explicitly distinguishes Require rule to elevate, Deny all, and Allow child processes to run elevated. In the allow mode, child processes automatically run elevated and rule evaluation is skipped, including deny rules. Microsoft recommends avoiding overly broad elevation rules for applications that can launch other processes, such as command shells or script engines.

  • Intune · App management
    Windows MAM guidance marks App Protection Conditional Access generally available

    The refreshed Windows Mobile Application Management prerequisites label App Protection Conditional Access as generally available and replace older fixed build references with the supported Windows versions page. They also state that the Mobile Threat Defense Connector for the Windows Security Center component is supported only on Windows 11 version 22631 (23H2) or later. The diff establishes the documented status and prerequisite, but does not provide a separate launch date.

  • Cloud PKI · Tenant administration
    Cloud PKI audit guidance specifies CA, certificate actions and prerequisites

    The new audit-log article lists actions including creating, searching, retrieving, updating, and deleting CAs; searching and revoking leaf certificates; uploading externally signed CA certificates; changing CA status; and revoking CA certificates. It directs administrators to Tenant Administration > Audit Logs or Microsoft Graph and lists a Cloud PKI license, Intune service administrator role, Graph access token, and DeviceManagementApps.Read.All or DeviceManagementApps.ReadWrite.All permissions as prerequisites.

For Intune administrators

Inventory Cloud PKI issuing CAs and the SCEP profiles that reference them. For an expiring CA, the documented path is to create a replacement with the same Root CA Source and matching Extended Key Usages and key sizes, then replace the SCEP URI in each profile; do not add a second URI, and remember that changing the URI does not trigger certificate reissuance. Review Autopilot deployment timeouts before assigning up to 25 apps, audit EPM rules for applications that can launch shells or script engines, and verify that Windows Security Center MTD connector targets run Windows 11 version 22631 (23H2) or later. Use the Cloud PKI audit guidance when validating required roles, licensing, Graph tokens, and permissions.
