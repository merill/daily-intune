Week in brief

Configuration Manager 2609 raises SQL prerequisites and retires Asset Intelligence reporting

The supplied week is a Configuration Manager 2609 readiness story rather than an Intune service update. The release table records build 5.00.9152.1000 as released September 28, 2026, with support through March 28, 2028; the consequential guidance adds SQL and ODBC gates, changes the SQL driver model, removes Asset Intelligence reporting, and drops support for older Windows Server client operating systems.

  • Configuration Manager · General
    SQL Server 2017 CU2 and ODBC 18.6.2.1 become 2609 gates

    For Configuration Manager 2609 and later, the prerequisite-check guidance requires SQL Server 2017 CU2 or later and ODBC Driver 18.6.2.1 or later. Unsupported versions can block installation or upgrades, and the page identifies incompatible ODBC releases to avoid.

  • Configuration Manager · General
    2609 removes SQL Server Native Client from new site prerequisites

    Starting in version 2609, Configuration Manager automatically installs the Microsoft OLE DB Driver for SQL Server and no longer requires SQL Server Native Client. Configuration Manager 2603 and earlier retain the previous Native Client behavior.

  • Configuration Manager · Endpoint analytics
    2609 removes the Asset Intelligence category and its 67 reports

    Starting with version 2609, the Asset Intelligence report category and all 67 reports are removed. The documentation specifies that these reports apply to Configuration Manager 2603 and earlier.

  • Configuration Manager · General
    TRUSTWORTHY is no longer required for 2609 SQLCLR loading

    Starting with Configuration Manager 2609, the TRUSTWORTHY database property is not required to load Microsoft-signed SQLCLR assemblies, including for databases using SQL Server Always On availability groups. Configuration Manager 2603 and earlier still require TRUSTWORTHY to be enabled.

  • Configuration Manager · General
    Older Windows Server client operating systems lose 2609 support

    Starting with Configuration Manager 2609, Windows Server 2012, Windows Server 2012 R2, and their Windows Storage Server editions are no longer supported as client operating systems.

For Intune administrators

Administrators running Configuration Manager in an Intune environment should inventory SQL Server and ODBC versions before installing or updating to 2609, then review dependencies on Asset Intelligence reports and older Windows Server clients. Apply the 2609-specific SQL database instructions, since Native Client and TRUSTWORTHY requirements differ from Configuration Manager 2603 and earlier. The supplied material identifies no Intune-only action.
