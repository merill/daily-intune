Week in brief

Purview DLP will add Intune multi-admin approval for Edge unmanaged apps

The week is dominated by author and ownership metadata maintenance, but several updates have direct planning value. Starting in November 2026, Purview DLP will add Intune multi-admin approval for unmanaged apps in Edge for Business. Intune also documented Windows 11 version 26H2 baseline guidance, changed its endpoint allowlist guidance, and recorded a regional Remote Help limitation. Adjacent Configuration Manager documentation describes version 2609 support changes, including the removal of legacy Windows Server client operating systems.

  • Intune · App management
    Purview DLP adds a November 2026 Intune approval workflow for Edge unmanaged apps

    Starting in November 2026, Microsoft Purview DLP will improve setup and support Intune multi-admin approval for unmanaged apps in Edge for Business. The change adds clearer status, detailed errors, and task coordination between Purview and Intune administrators; existing policies and enforcement remain unchanged.

  • Intune · General
    Windows 11 26H2 baseline guidance now covers Settings Catalog support

    Intune guidance now documents the Windows 11 version 26H2 security baseline, including new settings, updated defaults, and revised guidance. Existing security baseline profiles do not update automatically; adopting the 26H2 baseline requires creating a new profile or updating an existing one.

  • Intune · Fundamentals
    Endpoint guidance replaces regional allowlist entries with a global trouter wildcard

    The Intune endpoints table adds `*.trouter.communications.svc.cloud.microsoft` for all regions and removes the separate `go-amer`, `go-eu`, and `go-apac` entries. Administrators maintaining network allowlists should review them against the revised table.

  • Remote Help · General
    Remote Help documents a Switzerland North limit on Windows unattended sign-in

    Remote Help planning guidance now states that tenants in the Switzerland North datacenter region cannot use Windows unattended remote sign-in. That regional limitation needs to be included when planning Remote Help coverage.

  • Configuration Manager · General
    Configuration Manager 2609 ends support for legacy Windows Server client OSes

    Configuration Manager 2609 no longer supports Windows Server 2012, Windows Server 2012 R2, or their Windows Storage Server editions as client operating systems. Teams planning the upgrade should identify affected devices and move them to a supported Windows Server version.

For Intune administrators

Admins adopting the Windows 11 26H2 baseline must create a new profile or update an existing one because current profiles do not update automatically. Network teams should reconcile allowlists with the revised endpoint table. Remote Help planners in Switzerland North must account for the Windows unattended sign-in restriction. Configuration Manager teams should identify affected legacy server clients and upgrade them. The Purview change affects setup and approval coordination, while existing policies and enforcement remain unchanged.
