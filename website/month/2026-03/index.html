Month in brief

Intune Data Warehouse reset and hotpatch defaults set administrators’ next deadlines

March’s strongest Intune signals were operational rather than a single broad release. A planned Intune Data Warehouse change threatens reporting continuity; Windows Autopatch is preparing default hotpatch behavior for eligible devices; and Windows Autopilot device preparation now supports managed-installer sequencing before app installation. Security Copilot also has a phased Microsoft 365 E5 inclusion notice, while its Vulnerability Remediation Agent is documented as a limited public preview. Much of the remaining supplied material is documentation maintenance—path corrections, title cleanup, and clarifications such as Application control remaining template-based—so it should not be read as broad product behavior change.

  • Intune · Endpoint analytics
    Data Warehouse update resets history and ends the beta Power BI connector

    Microsoft’s Message Center places the Intune Data Warehouse infrastructure update in mid-June 2026. It will reset historical data to about 30 days, refresh surrogate keys, and revise licensing definitions. The beta Power BI connector will be discontinued; administrators must switch to the OData feed from the Intune admin center and back up data beforehand. This is a planned change, not a completed reset.

  • Intune · Device enrollment
    Windows Autopatch will default eligible Intune devices to hotpatching in May

    Starting May 2026, Windows Autopatch will enable hotpatch security updates by default for eligible Intune devices. An opt-out setting will be available from April 2026, while devices still need prerequisites such as Virtualization-based Security. Hotpatching is intended to speed security updates without requiring restarts.

  • Windows Autopilot · Device enrollment
    Autopilot device preparation adds managed-installer support before app deployment

    The updated Windows Autopilot device-preparation guidance says managed installer policy is applied during OOBE before Win32, Microsoft Store, and Enterprise App Catalog apps install. Those app types were previously skipped to avoid installation conflicts and deployment failures. This changes application sequencing for Autopilot device-preparation deployments.

  • Security Copilot · Developer
    Security Copilot begins phased Microsoft 365 E5 inclusion with 400 SCUs per 1,000 users

    Microsoft says Security Copilot inclusion with Microsoft 365 E5 will roll out from April 20 through June 30, 2026, providing 400 Security Compute Units per 1,000 users and core agentic features across Microsoft security products. Additional advanced capabilities may incur extra costs. This is a planned phased entitlement change, not evidence that every advanced Intune capability is included.

  • Security Copilot · Fundamentals
    Vulnerability Remediation Agent remains limited to select preview customers

    New Intune guidance identifies the Vulnerability Remediation Agent as a limited public preview available only to a select group of customers. It uses Microsoft Defender Vulnerability Management data to identify CVEs, prioritize remediation, and provide summarized impact analysis, suggested actions, affected systems, and step-by-step Intune remediation guidance. Administrators should not treat it as generally available; interested customers are directed to their sales team.

For Intune administrators

Back up Data Warehouse data, review dashboards and queries for refreshed surrogate keys and licensing-definition changes, and move from the beta Power BI connector to the Intune admin center’s OData feed before the expected mid-June update. Identify Autopatch-eligible devices, verify prerequisites such as Virtualization-based Security, and prepare for the April opt-out setting if the May default is unsuitable. For Autopilot device-preparation deployments, review managed-installer and app ordering. For Security Copilot, track the April 20–June 30 phased E5 rollout, the allocation of 400 Security Compute Units per 1,000 users, and possible charges for advanced capabilities. Do not plan broad Vulnerability Remediation access: the supplied guidance limits it to select preview customers.
