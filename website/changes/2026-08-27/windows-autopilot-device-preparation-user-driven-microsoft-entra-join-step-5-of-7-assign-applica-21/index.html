Windows Autopilot device preparation user-driven Microsoft Entra join - Step 5 of 7 - Assign applications and PowerShell scripts to device group

27 August 2026Doc update+7 / −6 lines

In brief

The tutorial now lists device association as an alternative to adding a Windows corporate identifier and clarifies the steps for deploying apps and PowerShell scripts.

What Intune admins need to know

Administrators have an additional documented setup path to follow when preparing devices; app and script assignments still target the designated device group.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.

Any applications installed or PowerShell scripts that run during a Windows Autopilot device preparation deployment should be configured to install in the System context since the applications are installed and the PowerShell scripts ran during OOBE when no user is signed in.

For applications to install and PowerShell scripts workto run successfully, they must be assigned to the device group created for Windows Autopilot device preparation in Step 3: Create an assigned device group.

For applications to install and PowerShell scripts workto run successfully during a Windows Autopilot device preparation deployment, complete two steps need to be taken:steps:

  1. They must be assigned to the device group created for Windows Autopilot device preparation in Step 3: Create an assigned device group. This step is covered in this article.
  2. They must be specified as part of the Windows Autopilot device preparation policy. This step is covered in the next step Step 5: Create Windows Autopilot device preparation policy.
!Note

The below steps assume that the applications or PowerShell scripts that will be deployed during Windows Autopilot device preparation deployment are already added to Intune.
