In brief

The endpoints documentation replaces the previous regional `lgmsape...blob.core.windows.net` entries with a larger list of `amsu...lmsas.blob.core.windows.net` endpoints.

What Intune admins need to know

Administrators managing firewall or outbound allowlists should review the updated endpoint list to support Windows Autopilot diagnostics uploads.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
