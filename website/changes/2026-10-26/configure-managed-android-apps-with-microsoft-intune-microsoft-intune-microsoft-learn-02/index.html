Configure Managed Android Apps with Microsoft Intune - Microsoft Intune | Microsoft Learn

26 October 2026New feature+32 / −11 lines

In brief

The documentation adds AOSP referenced apps alongside Android Enterprise apps, including platform and profile selections and JSON-only configuration guidance.

What Intune admins need to know

Administrators managing AOSP referenced apps should use vendor- or manufacturer-provided JSON settings. Configuration Designer and Connected apps aren't supported for these apps.

App configuration policies in Microsoft Intune supply settings to Managed Google Play apps and directly deployed line-of-business (LOB) apps on managed Android Enterprise devices, and to AOSP referenced apps on Android Open Source Project (AOSP) devices.

The app developer exposes Android-managedthe settings that you can configure. Assign an app configuration settings. Intune uses these exposed settingpolicy to let the admin configure features foruser or device groups to supply those settings to the app. The app configuration policy is assigned to your user groups. Theuses the policy settings are used when the appit checks for them, typically the first time the appit runs.

Important

Create an app configuration policy

Use this procedure to create an app configuration policy for managed Android Enterprise or AOSP devices.

  1. Sign in to the Microsoft Intune admin center.

  2. Choose the Apps > Configuration > Create > Managed devices. You can choose between Managed devices and Managed apps. For more information, see Apps that support app configuration.

  3. On the Basics page, set the following details:

    • Name - The name of the profile that appears in the portal.
    • Description - The description of the profile that appears in the portal.
    • Device enrollment type - This setting is set to Managed devices.

  4. Select Android Enterprise & AOSP as the Platform.

    Note

    For AOSP referenced apps, select All or Corporate owned devices as the Profile type.

  5. Select Select app next to Targeted app. The Associated app pane is displayed.

  6. On the Associated app pane, choose the managed app to associate with the configuration policy and select OK.

  7. Select Next to display the Settings page.

    • Use configuration designer
    • Enter JSON data

    Note

    AOSP referenced apps support JSON configuration only. Configuration designer isn't supported because Intune doesn't have an uploaded APK from which to read the app's configuration schema. Get the supported configuration keys, value types, and values from the app vendor or device manufacturer.

    For details about using the configuration designer, see Use configuration designer. For details about entering XMLJSON data, see Enter JSON data.

  8. If you need to enable users to connect the targeted app across both the work and personal profiles, select Enabled next to Connected apps.

    Note

    This setting only works for personally owned work profile and corporate-owned work profile devices. Connected apps isn't supported for AOSP referenced apps.

    Changing the Connected apps setting to Not Configured won't remove the configuration policy from the device. To remove the Connected apps functionality from a device, you must unassign the related configuration policy.

  9. ToFor supported Android Enterprise devices, select Credential provider to allow specific apps to act as a system credential provider, select Credential provider.provider. By default, Android blocks third-party credential providers from providing credentials. For more information, see Allow an app to be a credential provider.

  10. Select Next to display the Scope tags page.

  11. [Optional] You can configure scope tags for your app configuration policy. For more information about scope tags, see Use role-based access control and scope tags for distributed IT.

  12. Select Next to display the Assignments page.

You can use the configuration designer for Managed Google Play apps when the app is designed to support configuration settings. Configuration applies to devices enrolled in Intune. The designer lets you configure specific configuration values for the settings exposed by the app.

Configuration designer isn't supported for AOSP referenced apps. For these apps, use Enter JSON data.

  1. Select Add. Choose the list of configuration settings that you want to enter for the app.

    If you're using Gmail or Nine Work email apps, Android Enterprise device settings to configure email has more information on these specific settings.

Some configuration settings on apps (such as apps with Bundle types) can't be configured with the configuration designer. Use the JSON editor for those values. Settings are supplied to apps automatically when the app is installed.

For AOSP referenced apps, JSON is the only supported configuration format. Follow Create an app configuration policy and use configuration settings supplied by the app vendor or device manufacturer.

  1. For Configuration settings format, select Enter JSON editor.
  2. In the editor, you can define JSON values for configuration settings. You can choose Download JSON template to download a sample file that you can then configure.
  3. Choose OK, and then choose Add.

Applies to: Android 11+

Connected apps isn't supported for AOSP referenced apps.

Personally owned work profile users must have Company Portal version 5.0.5291.0 or newer. Corporate-owned work profile users don't need a specific version of the Microsoft Intune app for support.

You can allow users using Android personally owned and corporate-owned work profiles to turn on connected apps experiences for supported apps. This app configuration setting enables apps to connect and integrate app data across the work and personal app instances.

By default, Android blocks third-party credential provider apps from providing credentials. Use the Credential provider setting to allow specific apps (such as a third-party password manager) to act as the system credential provider. Microsoft Authenticator is allowed automatically.

To configure credential provider permissions, go to Apps > Configuration > Create > Managed devices, and choose Android Enterprise & AOSP as the platform. Select Credential provider in the settings to allow specific apps to act as credential providers.
