Tutorial Automated Ios

30 October 2026Doc update+2 / −4 lines

In brief

The tutorial now recommends Setup Assistant with modern authentication or Company Portal for User Affinity enrollment, with just-in-time registration recommended for modern authentication. Legacy Setup Assistant guidance was removed, and metadata was updated.

What Intune admins need to know

Administrators following the tutorial will see the revised authentication recommendations.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
