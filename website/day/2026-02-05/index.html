Day in brief

Endpoint Privilege Management support is coming to AVD single-session VMs

The period contains 123 documentation updates and no new or removed items. Most of the 115 Windows Autopilot updates are mechanical metadata cleanup, including removal of high-priority collection markers. The meaningful changes are an Autopilot known-issue status update and several capabilities listed as in development on Intune’s roadmap page.

  • Intune · Fundamentals
    EPM support is being added for AVD single-session environments

    Microsoft says it is adding support to deploy Endpoint Privilege Management policies to users on Azure Virtual Desktop single-session virtual machines. EPM elevation policies are expected to work in those environments once supported. The entry is explicitly in development, gives no general-availability date, and identifies EPM as an Intune Suite add-on capability.

  • Windows Autopilot · Device enrollment
    Windows Autopilot device preparation issue is marked resolved

    The known-issues page now adds an updated date of February 5, 2026 and states, “This issue was resolved in February 2026.” The supplied diff does not identify the issue or the fix, so this is a documentation status clarification rather than evidence of a newly released Autopilot behavior.

  • Intune · Fundamentals
    Android settings catalog will filter settings by management mode

    An in-development filter for Android settings catalog policies will narrow available settings by enrollment type: Fully managed (COBO), Corporate-owned work profile (COPE), or Dedicated (COSU). The change describes policy authoring and settings discovery; it does not state that existing policy behavior changes.

  • Intune · Fundamentals
    Apple catalog updates add an exemption setting and new security terminology

    The planned iOS/iPadOS Settings Catalog update adds Restrictions > Rating Apps Exempted Bundle IDs. It also reflects Apple’s rebranding of Rapid Security Responses as Background Security Improvements. No availability date or migration requirement for existing profiles is supplied.

  • Intune · Fundamentals
    Intune is developing a direct Lenovo Device Orchestration link

    A Partner portals integration in development will let administrators open the Lenovo Device Orchestration Portal directly from the Intune admin center for supported Windows 11 devices. The entry describes a portal link, not new Lenovo management controls inside Intune, and says it will apply when the feature becomes available.
