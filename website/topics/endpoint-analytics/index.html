Plan for Change: Removal of legacy Apple MDM software updates

Message CenterMC1470869 on mc.merill.net ↗Plan for change
Endpoint analytics

Apple has ended support for legacy MDM software update commands with OS 27. Intune will remove the legacy update UI in its October release. Admins must switch to declarative device management (DDM) for Apple software updates to ensure devices continue updating properly. Review and update policies accordingly.
