Day in brief

Intune driver policies now name the settings that block Windows driver installation

Windows driver update policy guidance now gives administrators precise allow values to check: Windows driver = Allow in update rings and Allow Windows Update drivers in Settings Catalog policies; both allow drivers by default. The period also removes the Driver Updates Overview page, records Endpoint Privilege Management policy support for Azure Virtual Desktop single-session VMs as in development, and adds Enterprise Agreement and sovereign-cloud boundaries to Autopatch guidance. An iOS line-of-business app note documents manual-downgrade behavior, while most other edits consolidate prerequisites or adjust layout and navigation.

  • Intune · Device updates
    Driver policy guidance identifies the settings that can block installation

    The Driver Updates Policy page now specifies that update rings should use Windows driver set to Allow, while Settings Catalog policies should use Allow Windows Update drivers. Both settings allow driver updates by default.

  • Intune · Device updates
    The Windows Driver Updates Overview page was removed

    The page covering Windows driver update policies, approvals, pauses, prerequisites, and supported editions was deleted, so administrators can no longer use it as a reference.

  • Endpoint Privilege Management · Device enrollment
    EPM lists AVD single-session support as in development

    The Endpoint Privilege Management In Development page now states that EPM policies will support users on Azure Virtual Desktop single-session virtual machines.

  • Intune · Device updates
    Autopatch guidance adds EA support routing and cloud boundaries

    The guidance directs administrators blocked from creating Autopatch-dependent policies with Enterprise Agreement licenses to contact their licensing source. It also states that subscription activation with an existing EA does not apply to GCC, GCC High, or DoD environments for Windows Autopatch capabilities.

  • Intune · App management
    iOS available-app guidance documents manual-downgrade behavior

    The iOS line-of-business app guidance now says an app targeted with available intent will not update automatically when the installed app was manually downgraded. It also clarifies terminology and bundle identifier guidance.
