In brief

The device management actions index updates its Rename entries to link to the bulk-rename-devices section of the device inventory and status documentation.

What Intune admins need to know

Administrators can use the updated links to navigate directly to bulk rename guidance; no action is required.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
