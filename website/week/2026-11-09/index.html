Week in brief

KB40345593 fixes 2603 token failures; account-driven Apple enrollment now specifies modern authentication

For the week of 9 November 2026, the standout operational item is KB40345593 for Configuration Manager 2603. It fixes bulk registration token verification failures for non-Microsoft Entra-joined devices connecting through a CMG after KB39169655. Intune’s revised automated-authentication guidance directs affected account-driven Apple User Enrollment scenarios to Option 2, Setup Assistant with modern authentication, and says the other method blocks enrollment for targeted users. Most remaining changes are documentation clarifications covering Windows Autopilot enrollment procedures, macOS shell-script execution, and Configuration Manager update sequencing rather than a broad feature rollout.

  • Configuration Manager · General
    KB40345593 fixes bulk registration token verification failures

    The fix applies to Configuration Manager version 2603 sites after KB39169655, covering non-Microsoft Entra-joined devices connecting through a CMG. Install it from Updates and Servicing; a site reset is required, existing secondary sites must be updated manually, and no computer restart is required.

  • Intune · Device enrollment
    Setup Assistant with modern authentication is specified for affected Apple enrollments

    The automated-authentication guidance explicitly directs administrators to Option 2: Setup Assistant with modern authentication for successful automated enrollments involving account-driven Apple User Enrollment. It says the other authentication method blocks enrollment for targeted users.

  • Intune · Endpoint analytics
    Intune clarifies macOS shell-script execution prerequisites and settings

    The revised guidance emphasizes a direct Internet requirement, run frequency, retries, and user context, while revising or removing some scope-tag, assignment, and retry-setting instructions. Administrators should check scripts against the updated execution guidance.

  • Windows Autopilot · Device enrollment
    Autopilot for Existing Devices changes the documented ESP navigation

    The setup instructions now separate Windows selection from the Windows Autopilot > Enrollment Status Page navigation, and the previous automatic-enrollment step is no longer included. Administrators consulting the article should follow the revised sequence.

  • Configuration Manager · Endpoint analytics
    Configuration Manager update guidance clarifies site order and distribution-point batching

    The article now explains starting updates at the top-level site, manually updating secondary sites, monitoring status, and staggering distribution point updates according to content-distribution settings. It also highlights that distribution points can go offline in batches.

For Intune administrators

For Configuration Manager 2603 sites with KB39169655, install KB40345593 from Updates and Servicing, plan for the required site reset, and manually update existing secondary sites; no computer restart is required. For affected account-driven Apple User Enrollment automated enrollments, use Option 2: Setup Assistant with modern authentication. Review the revised macOS shell-script execution guidance and Autopilot Enrollment Status Page navigation when using those procedures. Configuration Manager servicing plans should also account for manual secondary-site updates and distribution points going offline in batches.
