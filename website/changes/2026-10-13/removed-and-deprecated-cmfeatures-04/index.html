Removed And Deprecated Cmfeatures

13 October 2026Retirement+14 / −13 lines

In brief

The Configuration Manager documentation now lists the Exchange Server connector as deprecated, dated November 2021, with removal in the first release after November 1, 2022. Documentation metadata and reference links were also refreshed.

What Intune admins need to know

Administrators using the Exchange Server connector should account for its documented retirement timeline when planning Configuration Manager deployments.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
