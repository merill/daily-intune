Week in brief

Intune Data Warehouse plans mid-June reset and beta Power BI connector retirement

The period’s clearest operational change is a Message Center plan for an Intune Data Warehouse infrastructure update now expected in mid-June 2026. It would reduce historical data to about 30 days, refresh surrogate keys, revise licensing definitions, and discontinue the beta Power BI connector in favor of the OData feed. Intune guidance also records hotpatch as enabled by default for eligible devices and adds managed-installer support during Windows Autopilot device preparation. Much of the remaining activity is documentation restructuring: Settings Catalog content moved to new device-configuration paths, while new platform references and how-to guides appeared. Those changes should not be treated as blanket feature launches.

  • Intune · Endpoint analytics
    Data Warehouse plan puts reporting migration and backup on the roadmap

    The Message Center plan says the Intune Data Warehouse update is now expected in mid-June 2026. Historical data would be reset to about 30 days, surrogate keys refreshed, and licensing definitions revised. The beta Power BI connector will be discontinued; administrators are directed to switch to the OData feed from the Intune admin center and back up data beforehand.

  • Intune · Compliance
    Hotpatch guidance now states default enablement for eligible devices

    Updated Windows quality update guidance says hotpatch security updates are enabled by default for all eligible devices in Microsoft Intune, with control available through a tenant-level setting or quality update policies. During a hotpatch month, a device missing the latest baseline can receive both the baseline update, which requires a restart, and the hotpatch update. This is a documented behavior change, not a stated preview or general-availability announcement.

  • Windows Autopilot · Device enrollment
    Windows Autopilot device preparation adds managed installer support

    The Windows Autopilot device preparation update records support for managed installer policy during OOBE. The policy is applied before Win32, Microsoft Store, and Enterprise App Catalog apps install; those app types were previously skipped to avoid conflicts and deployment failures. The supplied evidence does not assign a preview or general-availability label.

  • Intune · Device security
    Defender integration guidance adds an explicit least-privilege RBAC matrix

    The Intune–Defender for Endpoint guidance now specifies Mobile Threat Defense Modify and Read permissions; Endpoint Detection and Response Assign, Create, Read, and Update; and Device compliance policies Assign, Create, Read, and Update. It identifies Endpoint Security Manager as the least-privileged built-in Intune role containing all required permissions, while Conditional Access requires a separate Microsoft Entra role. This is security guidance clarification rather than evidence of a new integration feature.

  • Intune · Apple
    Apple Settings Catalog guidance points toward future template migration

    The new Apple configuration reference recommends creating new policies in the Settings Catalog where possible and says Device features, Device restrictions, Endpoint protection, and Extensions templates are expected to migrate to the Settings Catalog in a future Intune release, after which creating new templates will be deprecated. Derived credential, Email, PKCS, SCEP, trusted-certificate, Wi-Fi, and wired-network policies remain listed as template cases. No retirement date is supplied, so this is forward-looking…

For Intune administrators

Reporting owners should back up Data Warehouse data before the expected mid-June update, review queries and dashboards for refreshed surrogate keys and licensing-definition changes, and migrate from the beta Power BI connector to the OData feed. Windows update teams should verify hotpatch tenant-level or quality-update policy settings and account for baseline updates still requiring a restart. Teams using Autopilot device preparation should review app sequencing because managed installer policy is now applied before Win32, Microsoft Store, and Enterprise App Catalog apps. Security administrators should check custom Intune roles against the newly documented Defender permissions and assign Conditional Access permissions separately in Microsoft Entra ID.
