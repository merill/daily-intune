Use a PKCS certificate profile to provision devices with certificates in Microsoft Intune

7 August 2026Doc update+5 / −2 lines

In brief

The PKCS profiles documentation now states that device configuration profiles containing PKCS certificate profiles aren't supported on Microsoft Teams devices running AOSP. The page date was also updated.

What Intune admins need to know

Admins managing AOSP-based Teams devices should account for this limitation when configuring certificate profiles. No mandatory action is stated.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
