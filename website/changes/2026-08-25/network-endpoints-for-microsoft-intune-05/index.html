Network endpoints for Microsoft Intune

25 August 2026Feature updateAction required+2 / −1 lines

In brief

The endpoints documentation now states that Remote Sign-in for Remote Help on Windows requires Azure Virtual Desktop session host endpoints.

What Intune admins need to know

Administrators using unattended access should verify that these endpoints are permitted in their network configuration.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
