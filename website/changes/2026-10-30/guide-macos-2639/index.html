30 October 2026Retirement+7 / −29 lines

In brief

The guide states that support for Setup Assistant (legacy) authentication with ADE user affinity ended in the October 2026 (2610) service release. Existing legacy profiles are automatically updated to modern authentication. It also clarifies that Company Portal isn't supported for enrollments without user affinity.

What Intune admins need to know

Review enrollment behavior and user communications: user-affinity enrollments use modern authentication, with Company Portal sign-in after enrollment to complete Microsoft Entra registration. No administrator migration is specified because existing profiles update automatically.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.

Important

Intune has ended support for Setup Assistant (legacy) authentication for ADE with user affinity with the October 2026 (2610) service release. Existing profiles that use legacy authentication are automatically updated to Setup Assistant with modern authentication. Already-enrolled devices aren't affected and remain enrolled.
