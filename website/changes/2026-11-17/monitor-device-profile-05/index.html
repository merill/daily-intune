Monitor Device Profile

17 November 2026Doc update+7 / −1 lines

In brief

The documentation now states that the Google Workspace authentication setting reports Error until authentication is completed, but this does not change the device’s overall compliance state.

What Intune admins need to know

Check the user’s authentication status before troubleshooting a deployment failure; the setting’s Error status alone does not indicate overall device noncompliance.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
