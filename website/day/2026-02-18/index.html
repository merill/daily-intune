Day in brief

Remote Help guidance now requires dedicated Android devices for unattended access

The clearest administrator-relevant change is Remote Help’s revised unattended-access prerequisite: the updated guidance names Android Enterprise dedicated devices and no longer lists fully managed devices. Configuration Manager also received updated 2509 Connected Cache hotfix instructions, while Intune and co-management updates mainly clarify applicability, supported Windows terminology, and administrator roles. The remaining edits are largely documentation maintenance, including shared Global Administrator callouts, capitalization, screenshot metadata, and Connected Cache wording.

  • Remote Help · Device enrollment
    Remote Help guidance narrows the Android unattended-access prerequisite

    The updated Remote Help page states that unattended access requires an Android device enrolled as an Android Enterprise dedicated device. The previous wording also allowed fully managed devices. This is a documentation change, so validate the requirement in affected designs without assuming the service behavior itself changed.

  • Configuration Manager · General
    Configuration Manager 2509 hotfix guidance updates the Connected Cache installer

    The instructions replace DoincInstall.exe version 1.5.5.9002 with version 1.5.6.44280, listed as a 31.1 MB file dated 2/18/2026. When applying the hotfix, the procedure says to copy the executable to {SMSInstallDir}\bin\x64 on all site servers, including the CAS if present and passive sites.

  • Intune · Fundamentals
    Multi Admin Approval scope now explicitly includes compliance and Settings catalog policies

    The Intune guidance now lists creating and managing compliance policies and creating and managing configuration policies through the Settings catalog as covered activities. It continues to state that app deployments are covered while app protection policies are not. The evidence supports an applicability clarification, not a newly announced workflow.

  • Configuration Manager · General
    Co-management enrollment guidance now points to supported Windows versions

    The Configuration Manager enablement procedure changes the **All** automatic-enrollment description from clients running Windows 10 version 1709 or later to clients running supported Windows versions. It also removes the Windows 10-or-later qualifier from the co-managed-device workload description. Administrators should use the linked supported-devices list rather than infer that the supported platform range expanded.

  • Windows Autopilot · Device enrollment
    Autopilot OEM registration guidance names the approving role explicitly

    The OEM registration page now says that the organization’s Microsoft Entra Global Administrator must approve the OEM, replacing the more general wording that the organization must grant permission. The page also adopts a shared Global Administrator guidance include; the supplied evidence indicates terminology and documentation consolidation rather than a changed authorization workflow.
