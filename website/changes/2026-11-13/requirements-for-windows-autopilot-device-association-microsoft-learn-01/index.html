Requirements for Windows Autopilot device association | Microsoft Learn

13 November 2026Feature update+21 / −11 lines

In brief

The requirements page now includes a Hardware category and explicitly requires physical devices with TPM 2.0 enabled and healthy, not in Reduced Functionality Mode, and compliant with FIPS 186-3 or newer and TLS 1.3.

What Intune admins need to know

Administrators should validate device hardware and TPM compatibility before using Windows Autopilot device association.

Requirements for Windows Autopilot device association | Microsoft Learn

The list of requirements for Windows Autopilot device association is organized into fourfive categories:

  • Software - OS requirements.
  • Hardware - Physical device and Trusted Platform Module (TPM) requirements.
  • Networking - Networking requirements.
  • Licensing - Licensing requirements.
  • RBAC - RBAC permissions required for Windows Autopilot device association.

Software

Software requirements

Important

Device association requires a physical device. Virtual machines aren't supported.

Windows 11

  • Windows 11, version 25H2 with KB5120998 or later.
  • Windows 11 Education.
  • Windows 11 Enterprise LTSC.

Trusted Platform Module (TPM)

Hardware

Hardware requirements

Important

Device association requires a physical device—virtual. Virtual machines aren't supported. Each device must have TPM 2.0, enabled and in a good state. The TPM shouldn't be in Reduced Functionality Mode.

Trusted Platform Module (TPM)

TPM attestation is enforced during association: device association uses the TPM to attest the device's identity before enrollment.

TPM requirements:

  • Each device must have TPM 2.0, enabled and in a good state.
  • The TPM shouldn't be in Reduced Functionality Mode.
  • TPM must be FIPS 186-3 or newer compliant.
  • TPM must support TLS 1.3.
