Week in brief

KB36495448 fixes co-managed scan-source errors that redirect Intune updates to WSUS

The period's most consequential change is a Configuration Manager hotfix for co-managed environments where third-party updates can leave a partial Windows Update scan-source policy, sending Feature and Quality Updates to WSUS/ConfigMgr instead of Intune or Windows Update for Business. Intune also added concrete Recovery Lock guidance for macOS and a Windows 11 25H2 security-baseline reference. Service-release notes identify a Windows MDM-enrollment control as public preview and Admin tasks as generally available. Most other edits were link restructuring, terminology corrections, and procedure cleanup.

  • Configuration Manager · General
    Configuration Manager hotfix stops co-managed update-source redirection

    Fix and administrator action: KB36495448 applies to Configuration Manager 2503 with update rollup 32851084 and to version 2509 when third-party updates are enabled on co-managed devices. The defect can route Feature Updates and Quality Updates intended for Intune or Windows Update for Business to WSUS/Configuration Manager. After the hotfix, the client stops setting the affected scan-source values and cleans up the incomplete prior state.

  • Intune · Apple
    Recovery Lock gets macOS settings-catalog prerequisites and procedures

    New configuration guidance: the Intune how-to says Recovery Lock generates a strong random password, protects recovery-partition and Startup Options access, supports time-based rotation, and can be rotated through device actions. It applies to enrolled and supervised macOS 11.5-or-later devices using Apple silicon; Intel Macs are excluded. Creating the policy requires the documented policy-profile role, while rotation and viewing require custom remote-task permissions.

  • Intune · Device security
    Intune security-baseline reference adds Windows 11 version 25H2

    Security guidance: the Security Baseline Settings page adds a Version 25H2 pivot based on the Windows 11 version 25H2 baseline from the Security Compliance Toolkit, limited to settings applicable to Intune-managed Windows devices. Examples include enabled lock-screen camera and slideshow prevention, enabled UAC restrictions for local-account network logons, a disabled SMB v1 server, and the recommended disabled MrxSmb10 driver. This is a reference-content addition, not evidence that existing tenant policies changed

  • Intune · Apple
    Windows enrollment control enters public preview as Admin tasks reaches GA

    Preview and general availability: the new `Disable MDM enrollment when adding work or school account on Windows` setting controls MDM enrollment during account registration and defaults to No, which allows enrollment. The same service-release note says Admin tasks is out of preview and generally available, providing a centralized searchable and filterable view of common administrative tasks under Tenant administration.

  • Intune · Fundamentals
    Windows settings catalog adds Edge printing and geolocation controls

    New settings: the Windows settings catalog now documents Edge controls for showing an informational Edge for Business page after major browser updates, silent printing, and URL-based allow or block lists for precise geolocation. The informational-page policy applies only to Microsoft Entra ID profiles and is available starting with Edge version 144; the geolocation policies support wildcard URL patterns.

For Intune administrators

Check Configuration Manager 2503 deployments with update rollup 32851084 and version 2509 for applicability of KB36495448, particularly where third-party updates and co-management are used. For Recovery Lock, verify macOS 11.5 or later, Apple silicon, enrollment, supervision, and the required policy or remote-task permissions. Review 25H2 baseline defaults before updating security profiles. The Windows enrollment preview defaults to No, so no change is required unless you intend to disable MDM enrollment during account registration.
