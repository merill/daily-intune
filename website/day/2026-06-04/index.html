Day in brief

Configuration Manager guidance now calls legacy CMG images unsupported as 2027 enforcement approaches

This was a documentation-heavy day rather than a feature-launch day. The most consequential edit says legacy Configuration Manager CMG images are no longer compliant or supported, while Intune government-cloud guidance clarifies that commercial-to-government moves require device unenrollment and re-enrollment. A related GCC High and DoD service-description page replaces Common Criteria/NIAP wording with STIG lockdown guidance. Remote Help release notes describe reliability improvements, but updated entries give conflicting Windows version numbers. The remaining Intune edits are largely editorial, including Apple wired-network requirement ordering and wording corrections.

  • Configuration Manager · Windows
    Legacy CMG images are described as already noncompliant and unsupported

    The revised Configuration Manager hotfix text changes the wording from future to present: legacy images “are no longer compliant or supported” and won’t receive new OS patch updates through image refresh. It retains early 2027 as the point when new CMG deployments and reimaging operations that reference those images fail, and continues to identify the `windowsserver2022` image offer as the replacement. The page also presents availability in Updates and Servicing for version 2603, or versions 2503 and 2409 with KB 伽

  • Intune · Fundamentals
    Government-tenant guidance spells out the required migration procedure

    The reorganized Government Service page places the guidance under “Intune commercial and government instances” and “Enroll in government tenant.” It states that resources moving from a commercial tenant to government cloud require devices to unenroll from the current tenant and re-enroll in the new tenant; there is no built-in migration between the services. This clarifies the documented procedure rather than adding an in-place migration capability.

  • Intune · Fundamentals
    GCC High and DoD guidance shifts from certification wording to STIG help

    The service-description edit removes the statement that Intune is Common Criteria certified and on the NIAP Product Compliance List, along with the NIAP certification-material link. It adds guidance that administrators can get help locking down their Intune tenants using the Secure Technical Implementation Guide (STIG). The documentation diff alone does not establish that Intune’s certification status changed.

  • Remote Help · Windows
    Remote Help reliability notes leave the Windows build reference inconsistent

    The Week of June 1 entry identifies Remote Help for Windows version 1.0.2510071 and describes general bug fixes and performance improvements to enhance reliability. A separate updated Index entry gives the same description with version 5.2.1037.0, so the supplied What's new content does not provide a consistent build reference.
