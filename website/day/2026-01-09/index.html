Day in brief

Windows update policy guidance makes rollout choices and prerequisites explicit

New feature and quality update policy guidance describes the choices administrators make between required and optional deployments, Hotpatch readiness, and expedited-update compatibility. The day’s broader MTD changes are largely documentation maintenance, while the material Windows update additions are operationally significant.

  • Intune · Device updates
    Feature update policies gain required-versus-optional rollout guidance

    The new guide explains that a policy can hold a device to a chosen Windows version, expose the update as required or optional, and use rollout options for timing. Optional updates require Windows Autopatch licensing and need user action; changing between optional and required affects only devices that have not progressed too far into installation.

  • Intune · Device updates
    Quality update policy lists Hotpatch and expedite compatibility checks

    The new policy checklist points administrators to quality-update prerequisites and warns that preview builds, some update-ring choices, and Group Policy values such as WSUS location, Automatic Updates, feature deferral, and Disable Dual Scan can interfere with expedited deployment.

  • Intune · Device updates
    Expedited update guidance separates prerequisites from deployment behavior

    The updated documentation moves shared network, tenant, platform, device-configuration, and RBAC requirements into common content. It specifies that Update Health Tools remain necessary before Windows 11 24H2, while expedited policies still override quality deferrals for urgent servicing rather than normal monthly management.
