Week in brief

Cloud-native Windows tutorial removes its Windows in cloud configuration comparison

This was a quiet Intune period with one documentation-only update. The Cloud Native Windows Endpoints tutorial removed its tip linking to Windows in cloud configuration, the table contrasting the two approaches, and the Windows 10 support callout. The edit does not indicate a product, policy, or configuration-behavior change.

  • Intune · Windows
    Comparison guidance removed from the cloud-native Windows tutorial

    The tutorial no longer includes the Microsoft-recommended, standardized-solution tip; the comparison table stating that the tutorial helps administrators create their own configuration while Windows in cloud configuration applies a pre-built configuration for frontline, remote, and other focused-use workers; or the note that the two approaches can be combined. The Windows 10 support include was also removed. This is an ordinary documentation change, not evidence of changed Intune functionality.

For Intune administrators

Administrators evaluating cloud-native Windows deployments should use the linked solution documentation directly to decide between creating a custom configuration and using Windows in cloud configuration. Existing deployments are not identified as requiring changes.
