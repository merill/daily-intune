In brief

The option must be set to No and will soon be removed. The Sync with computers setting was deprecated by Apple in iOS 13 and is no longer included in enrollment policies.

What Intune admins need to know

Set Run Company Portal in Single App Mode until authentication to No in applicable enrollment policies.
