Day in brief

Intune Win32 apps gain uploaded PowerShell scripts for installation

The clearest capability change is in Win32 app creation: administrators can upload a PowerShell script instead of specifying a command line, with Intune packaging and running it in the app installer’s context. The broader period refreshes Windows Update guidance with actionable detail on expedited quality updates, feature-update policy transitions, Autopilot provisioning, and a newly documented OOBE update-scan failure mode.

  • Intune · Fundamentals
    Win32 app creation accepts PowerShell installation scripts

    The What's New entry says administrators can upload a PowerShell script instead of specifying a command line when adding a Windows Win32 app. Intune packages the script with the app content and runs it in the app installer’s context, enabling workflows such as prerequisite checks and configuration changes.

  • Intune · Device updates
    Feature Updates guidance clarifies Autopilot and Autopatch behavior

    The revised guidance covers update-ring settings, paused updates, Autopilot provisioning timing, group validation, and automatic Windows Autopatch enrollment. It states that devices remain enrolled in Autopatch after policy removal and receive no feature update until reassigned or explicitly unenrolled. Administrators should review overlapping rings and policy application after Autopilot provisioning.

  • Intune · Device updates
    Quality Updates policies document expedited security servicing prerequisites

    The article explains how Quality Updates policies deploy eligible Windows security updates without changing monthly update policies. Devices running Windows versions before 24H2 require Update Health Tools; the guidance also covers update selection, deferral overrides, and restart behavior. Expedited policies can be used for urgent security updates while update rings handle regular servicing.

  • Windows Autopilot · Device enrollment
    Autopilot OOBE quality-update scans may time out on newer devices

    A new known issue affects devices with KB5041571 and later when Allow OOBE Updates is enabled in the Enrollment Status Page profile. Quality Update scans may time out during OOBE, leaving updates uninstalled during provisioning. The issue is under investigation, so administrators should account for this outcome when troubleshooting deployments.

  • Enterprise App Management · App management
    Enterprise App Catalog scripts require post-creation changes with MAA

    PowerShell script overrides replace the standard install and uninstall commands. In tenants with Multi-Admin Approval enabled, scripts cannot be uploaded during app creation; they must be added or modified afterward. When no Microsoft Entra user is present, the scripts run in system context. Administrators should create the app first in MAA-enabled tenants and test the override behavior.
