Manage System Settings

28 October 2026Doc update+6 / −0 lines

In brief

The documentation now states that EPM System settings (Network settings) is rolling out gradually and may not yet be available in some tenants. Two supporting ontology links were also added.

What Intune admins need to know

Administrators may not see this setting in their tenant yet; no action is required.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
