Ref Settings Windows

16 November 2026Doc update+7 / −3 lines

In brief

The documentation now includes separate Allowed data sources and Allowed data destinations entries, with options and a Microsoft Edge note for No destinations. The page metadata date was also updated.

What Intune admins need to know

Administrators can use the expanded reference to distinguish and configure permitted data sources and destinations.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.

Receive data from Select one of the following options to specify the sources org users can receive data from:
- All sources: Org users can open data from any account, document, location, or application into the org context.
- No sources: Org users can't open data from external accounts, documents, locations, or applications into the org context. NOTE: For Microsoft Edge, No sources controls file upload behavior either via drag and drop or the file open dialog. Local file viewing and sharing files between sites/tabs is blocked.
- Selected apps: Org users can open data only from allowed data sources into the org context.		 All sources
Allowed data sourcesSelect one of the following options to specify the sources org users can receive data from:
- No sources: Org users can't open data from external accounts, documents, locations, or applications into the org context.
- OneDrive for Business: Org users can open data only from OneDrive for Business into the org context. Support for this setting will be introduced in a Microsoft Edge update to be released in the first quarter of calendar year 2027. Users will need that version or a later version for this setting to apply. This page will be updated with the specific version number when it becomes available.		No sources
Send org data to Select one of the following options to specify the destinations org users can send data to:
- All destinations: Org users can send org data to any account, document, location, or application.
- No destinations: Org users can't send org data to external accounts, documents, locations, or applications from the org context. NOTE: For Microsoft Edge, No destinations blocks file download. This means sharing files between sites/tabs are blocked.
- Selected apps: Org users can send org data to allowed data destinations from the org context.		 All destinations
Allowed data destinationsSelect one of the following options to specify where org users can send org data:
- No destinations: Org users can't send org data to external accounts, documents, locations, or applications from the org context. For Microsoft Edge, No destinations blocks file downloads and file sharing between sites or tabs.
- OneDrive for Business: Org users can send org data to OneDrive for Business from the org context. This setting requires Microsoft Edge version 158 or later.		No destinations
Allow cut, copy, and paste for Select one of the following options to specify the sources and destinations org users can cut or copy or paste org data:
- Any destination and any source: Org users can paste data from and cut/copy data to any account, document, location, or application.
- No destination or source: Org users can't cut, copy, or paste data to or from external accounts, documents, locations or applications from or into the org context. NOTE: For Microsoft Edge, No destination or source blocks cut, copy, and paste behavior within the web content only. Cut, copy, and paste are disabled from all web content, but not application controls, including the address bar.
- Org data destinations and any source: Org users can paste data from any account, document, location or application and cut/copy data to other org documents, locations or applications.
- Org data destinations and org data sources: Org users can cut or copy org data within the org context to other org documents, locations or applications. Org users can paste data within the org context into other org documents, locations or applications.		 Any destination and any source
