Week in brief

Defender for Android ends enrolled personal-profile protection by March 2026

Microsoft Defender for Android will stop protecting personal profiles on enrolled devices by March 2026, focusing instead on corporate work profiles; unenrolled devices are unaffected. In June 2026, Microsoft Entra Conditional Access will retire the “Require approved client app” control and direct organizations to “Require application protection policy.” Microsoft also plans to remove all Intune guided scenarios except Windows 365 Boot from the Intune admin center in March, without affecting existing configurations. Outside these notices, the most useful documentation changes clarify license-driven migration behavior and recommend Windows Update policies rather than Win32 apps for .msu packages; many other edits were navigation, formatting, or wording maintenance.

  • Intune · App management
    Microsoft Defender for Android drops enrolled personal-profile protection

    Microsoft Defender for Android will end support for protecting personal profiles on enrolled devices by March 2026 and focus solely on corporate work profiles. Work profiles and unenrolled devices are unaffected, and the notice says no administrator action is required.

  • Intune · Compliance
    Conditional Access retires Require approved client app in June

    Microsoft Entra Conditional Access will retire the “Require approved client app” control in June 2026. Microsoft directs organizations to use “Require application protection policy” for equivalent and enhanced protection; after retirement, the old control will no longer be enforceable.

  • Configuration Manager · Android
    Intune guided scenarios leave the admin center in March

    Starting in March 2026, all Intune guided scenarios except Windows 365 Boot will be removed from the Intune admin center. Existing configurations remain unaffected, and Microsoft says no administrator action is needed.

  • Intune · Fundamentals
    Migration guidance spells out the Intune license policy switch

    The migration guide now states that assigning Intune licenses switches users to Intune management and that Basic Mobility and Security policies no longer apply to users assigned Intune. It adds policy-mapping and license-assignment guidance and recommends removing old policies.

  • Intune · App management
    Windows update guidance moves .msu deployments toward update policies

    For .msu packages, the guidance now recommends Windows Update policies—including update rings, feature updates, and quality updates—instead of deploying updates as Win32 apps. The documentation does not state a required configuration change.

For Intune administrators

Conditional Access administrators should replace “Require approved client app” with “Require application protection policy” before June 2026 because the former will no longer be enforceable. No action is required for the Defender or guided-scenario changes: work profiles remain protected, and existing guided-scenario configurations remain unaffected. Migration teams should account for Intune license assignment switching users to Intune management and review or remove obsolete Basic Mobility and Security policies as recommended. Teams distributing .msu packages should review the policy-based deployment guidance; no required reconfiguration is stated.
