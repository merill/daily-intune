Week in brief

Endpoint Privilege Management reaches AVD single-session users, with all-user approval guidance

Endpoint Privilege Management carries the clearest product story this week: service-release notes add support for users on Azure Virtual Desktop single-session virtual machines, while updated support-approved guidance says elevation requests can come from any device user rather than only the primary user. Other consequential changes affect report populations, Hybrid Entra join Autopilot reliability, and Microsoft Connected Cache for co-managed Intune Win32 apps. The period was otherwise documentation-heavy; the Defender vulnerability article is a guidance clarification that now uses Microsoft Defender Vulnerability Management terminology and spells out prerequisites, not evidence of a newly launched integration.

  • Intune · Fundamentals
    New EPM support covers AVD single-session virtual machines

    Service release 2601 states that Endpoint Privilege Management elevation policies now support deployment to users on Azure Virtual Desktop single-session virtual machines. This is a new capability listed under the Microsoft Intune Suite.

  • Endpoint Privilege Management · Device security
    Support-approved EPM guidance now includes all users of a device

    The updated guidance says support-approved elevation requests can be submitted by all users of a device and are not limited to its primary user. This changes the documented prior limitation; the supplied update does not provide a separate rollout date.

  • Intune · Endpoint analytics
    Intune will exclude devices inactive for 12 months from reports

    Starting in late February 2026, Intune will exclude devices inactive for 12 or more months from reports. Reported device counts may decrease, and Microsoft says no action is needed; devices must check in to remain in reports.

  • Windows Autopilot · Device enrollment
    Hybrid Entra join Autopilot timeouts get OS-specific fixes

    A February 9 Known Issues entry says Microsoft Entra hybrid join Autopilot deployments might time out with error 0x80004005. The issue is resolved by KB5065789 or later for Windows 11, version 25H2; KB5065426 or later for 24H2; and KB5070312 or later for 23H2.

  • Configuration Manager · General
    Configuration Manager hotfix targets co-managed Intune Win32 downloads

    New version 2603 guidance addresses Microsoft Connected Cache not being used as expected for Win32 apps deployed through Intune in a co-managed environment, where IntuneManagementExtension.log shows an internet-based DownloadURL. The procedure uses DoincInstall.exe version 1.5.5.9002, temporarily disables and re-enables MCC on affected distribution points, or uses resetdps.trn for large sites. The page lists Configuration Manager versions 1910 through 2603 as prerequisites.

For Intune administrators

AVD administrators using EPM can assess deployment to single-session VMs, and EPM support-approved workflows should account for requests from non-primary users. Reporting owners should expect possible lower counts from late February when devices inactive for 12 or more months are excluded; Microsoft says no action is required, but devices must check in to remain in reports. For affected Autopilot deployments, verify that the relevant OS build includes the listed KB. Co-managed sites that see an internet-based DownloadURL for Intune Win32 content should follow the Connected Cache hotfix procedure. For Defender remediation, verify the newly documented Intune Plan 1, Defender for Endpoint, connection, onboarding, and risk-assessment prerequisites before rollout.
