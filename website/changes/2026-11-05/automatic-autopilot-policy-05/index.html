Automatic Autopilot Policy

5 November 2026Feature update+4 / −2 lines

In brief

The Apps section documentation now states that up to 25 managed applications can be selected for deployment, increased from 10. It also adds links for Enterprise App Catalog and its auto-update apps.

What Intune admins need to know

Administrators can select more essential applications for installation before users access the device.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
