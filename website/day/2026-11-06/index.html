Day in brief

Configuration Manager 2609 disables CMG shared keys and adds Azure prerequisites

The 2609 guidance states that CMG storage shared-key access is automatically disabled, including for existing deployments. It adds service-principal role-assignment permissions and Microsoft.Maintenance registration requirements. Separately, Intune’s Windows bulk enrollment guidance changes token validity from 180 days to 90 days.

  • Configuration Manager · General
    CMG storage shared-key access is disabled from version 2609

    Configuration Manager guidance now states that shared-key access is automatically disabled for CMG storage starting with version 2609, including existing deployments. It also distinguishes storage keys from application secrets.

  • Configuration Manager · General
    CMG updates require storage role assignments and provider registration

    Starting in version 2609, the CMG server application requires permission to manage storage role assignments, and Microsoft.Maintenance must be registered for the subscription. Missing permissions can cause deployment updates to fail with HTTP 403 errors.

  • Intune · Device enrollment
    Windows bulk enrollment token validity is now documented as 90 days

    Intune’s Windows bulk enrollment package instructions specify that bulk tokens are valid for 90 days instead of 180 days, requiring administrators to plan for earlier token expiration.
