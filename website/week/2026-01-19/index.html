Week in brief

Require approved client app retires in June; switch to application protection policy

The biggest admin signal is the June 2026 retirement of Microsoft Entra Conditional Access's **Require approved client app** control; a second Message Center notice says Microsoft Defender for Android will stop protecting personal profiles on enrolled devices by March 2026. The 63-record period was otherwise mostly documentation maintenance, but it also records OS enforcement for **Install Windows quality updates** in the `2026-01 B` quality update and clarifies scalar-property rules for Advanced Analytics Device Query. New Managed Home Screen pages document suspend and restore procedures for Android Enterprise corporate-owned Fully Managed and Dedicated devices; the supplied evidence does not establish a preview or general-availability launch.

  • Intune · Compliance
    Conditional Access control has a June 2026 retirement deadline

    Microsoft says the **Require approved client app** control will retire in June 2026 and will no longer be enforceable. Organizations should update affected policies to use **Require application protection policy** for equivalent and enhanced protection. This is a Message Center retirement notice.

  • Intune · App management
    Defender for Android drops enrolled personal-profile protection

    By March 2026, Microsoft Defender for Android will end support for protecting personal profiles on enrolled devices and focus solely on securing corporate work profiles. Work profiles and unenrolled devices are unaffected, and Microsoft says no admin action is required.

  • Intune · Device enrollment
    Windows quality-update enforcement is tied to 2026-01 B

    In the Enrollment Status Page guidance, the **Install Windows quality updates** statement changed from saying the setting was available but not yet enforced by the OS, with enforcement planned for `2026-01 B`, to saying OS enforcement is included in the `2026-01 B` quality update. This updates the documented enforcement status rather than announcing a new policy setting.

  • Advanced Analytics · Endpoint analytics
    Advanced Analytics requires scalar properties in Device Query operators

    The Device Query reference now says the `Device` entity cannot be used directly in scalar-requiring operators such as `distinct`, `summarize`, and `order by`. Administrators should use a specific scalar property instead, such as `Device.SerialNumber` or `Device.OSVersion`. This is a query limitation clarification.

  • Intune · App management
    Intune now recommends Windows Update policies over Win32 .msu packages

    The updated Windows update package guidance explicitly says deploying an `.msu` file as a Win32 app isn't the recommended approach and points administrators to Update rings, Feature updates, and Quality updates. Win32 deployment remains an option when more granular control is needed; this is operational guidance, not a change to the Win32 capability.

For Intune administrators

Before June 2026, find Conditional Access policies using **Require approved client app** and replace the control with **Require application protection policy**; after retirement, the old control will no longer be enforceable. No admin action is required for the Defender scope change, which doesn't affect corporate work profiles or unenrolled devices. If you use Device Query, change scalar operators to use properties such as `Device.SerialNumber` or `Device.OSVersion`. For normal Windows update deployment, follow the recommended Update rings, Feature updates, or Quality updates path rather than packaging `.msu` files as Win32 apps; use the Win32 method only when granular control is needed.
