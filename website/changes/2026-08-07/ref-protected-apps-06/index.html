Ref Protected Apps

7 August 2026Doc update+0 / −1 lines

In brief

The protected apps reference no longer includes the Klaxoon for Intune listing.

What Intune admins need to know

Administrators reviewing the protected apps reference will see this app is no longer listed; no action is specified.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
