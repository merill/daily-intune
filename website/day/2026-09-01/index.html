Day in brief

Autopilot guidance flags hybrid-join pre-provisioning failures when policies need domain controllers

The period was overwhelmingly mechanical: 863 of 873 updates were Configuration Manager entries, with representative pages standardizing documentation metadata from `core-infrastructure`/`microsoft-endpoint-configuration-manager` to `core-infra`/`configuration-manager`. The meaningful administrator-facing changes covered an Autopilot pre-provisioning failure condition, Remote Help licensing for Android COSU devices, and a more prominent Intune servicing warning.

  • Windows Autopilot · Device enrollment
    Autopilot documents a hybrid-join pre-provisioning failure condition

    The Windows Autopilot known-issues guidance now explains that pre-provisioning for Microsoft Entra hybrid join can fail when policy conflict resolution requires domain controller connectivity, especially when a BYO VPN is unavailable during technician flow.

  • Remote Help · Device enrollment
    Remote Help licensing is clarified for Android COSU deployments

    Supported Zebra and Samsung devices running Android Dedicated Device (COSU) mode don't require a Sharer license; only the Helper needs a Remote Help license.

  • Intune · Compliance
    Intune servicing guidance raises its callout from Caution to Important

    The Servicing Information page changed the callout from Caution to Important. The message itself is unchanged: required Microsoft cloud-service communication can affect updates, reliability, security mitigations, and feature enablement.

  • Configuration Manager · Device security
    Configuration Manager documentation adopts new service metadata identifiers

    Representative Configuration Manager pages now use `ms.subservice: core-infra` and `ms.service: configuration-manager` instead of `core-infrastructure` and `microsoft-endpoint-configuration-manager`. This is a documentation classification change with no specified administrator action.
