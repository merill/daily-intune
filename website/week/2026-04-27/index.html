Week in brief

Configuration Manager 2603 brings Network Access Account hardening and an October co-management deadline

The 248-item period was dominated by documentation maintenance—241 updates versus four new entries—but several changes have direct operational significance. Configuration Manager 2603 is the standout release item, while Intune adds Ubuntu 26.04 LTS support and documents Platform SSO registration during macOS Automated Device Enrollment. Other high-value updates clarify the Windows Security Center MAM connector procedure and unlicensed administrator defaults; most remaining edits are terminology, link, image, or formatting changes.

  • Configuration Manager · General
    Configuration Manager 2603 adds security fixes and an October compliance deadline

    The 2603 release is available as an in-console update installable at the top-tier site in a hierarchy. It restricts Network Access Account information to supported OSD media task-sequence scenarios. An internal service required for device compliance checks will be deprecated in October 2026; Software Center compliance checks may fail in co-managed environments where the Compliance workload is managed by Intune, so Microsoft says to apply the update before October. The release also removes the deprecated SQL Server

  • Intune · General
    Ubuntu 26.04 LTS support arrives before Ubuntu 22.04’s August deadline

    Intune now supports Ubuntu 26.04 LTS. Support for Ubuntu 22.04 LTS ends in August 2026, although devices already enrolled on 22.04 remain enrolled. Administrators can find them under Devices > All devices by filtering for Linux and adding the OS version column, then notify users to upgrade to a supported Ubuntu version.

  • Intune · General
    Platform SSO registration is documented for macOS Automated Device Enrollment

    The Intune What's new entry documents running Platform SSO during macOS ADE registration. Before enrollment, administrators must configure the settings catalog setting Enable Registration During Setup, deploy Company Portal version 5.2604.0 or newer as a line-of-business app, and configure ADE to use Setup Assistant with modern authentication and await final configuration. The scenario applies to macOS 26 and newer and gives users access to Microsoft Entra ID resources immediately at the desktop.

  • Intune · App management
    Windows Security Center MAM setup now requires an explicit connector toggle

    The revised Edge data-security procedure says to open the Windows Security Center connector after creating it, turn on Connect Windows devices for MAM, and save. The documented status is Available after creation and changes to Enabled only after the toggle is turned on, replacing earlier guidance that the connector remained Unavailable until an App Protection Policy arrived or a MAM user enrolled. This is a procedure and status-documentation change, not a stated preview or GA announcement.

  • Intune · Fundamentals
    Unlicensed administrator defaults now depend on tenant creation date

    Tenants created after July 2021 support unlicensed administrator access by default and require no action. Tenants created before July 2021 require the Allow access to unlicensed admins setting, and Microsoft says the setting cannot be undone after activation. The guidance also clarifies the limit of 350 unlicensed administrators per security group, that multiple groups can be used above that limit, and that nested-group members are not included.

For Intune administrators

Co-managed environments should apply Configuration Manager 2603 before October 2026 where the Compliance workload is managed by Intune. Intune administrators should identify Ubuntu 22.04 devices, use the documented prerequisites before deploying macOS Platform SSO during ADE, explicitly enable the Windows Security Center MAM toggle, and check tenant creation date before changing administrator licensing. The supplied PSSO entry does not label the capability as preview or generally available.
