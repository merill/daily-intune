Day in brief

Microsoft Defender for Android ends enrolled personal-profile protection by March 2026

Microsoft Defender for Android will end support for protecting personal profiles on enrolled devices by March 2026, focusing on corporate work profiles. Work profiles and unenrolled devices are unaffected, and Microsoft says no administrator action is required. The period’s other useful changes refine Intune migration, Advanced Analytics query syntax, and Remediations delivery guidance.

  • Intune · App management
    Personal-profile protection ends for enrolled Android devices

    The Message Center says Microsoft Defender for Android will stop protecting personal profiles on enrolled devices by March 2026 and focus on corporate work profiles. Work profiles and unenrolled devices are unaffected, and the notice requires no administrator action.

  • Intune · Fundamentals
    Intune migration guidance names required roles and policy cleanup

    The migration guide now instructs administrators to assign licenses and policies, identifies the Endpoint Security Manager and Conditional Access Administrator roles, and links to role details and guidance for removing unneeded Basic Mobility and Security policies.

  • Advanced Analytics · Endpoint analytics
    Device Query guidance adds join types and scalar-property rules

    Advanced Analytics documentation now lists nine supported join types, adding leftsemi, rightsemi, leftanti, and rightanti. It also clarifies that Device must be referenced through a scalar property, such as Device.DeviceId, for operators including distinct, summarize, and order by, with corrected aggregation examples.

  • Intune · Fundamentals
    Remediations guidance ties Run delivery to connectivity

    The Remediations page now states that a device will not receive the Run remediation action when it is offline or cannot communicate successfully with Intune or WNS when the action is sent. Administrators should account for connectivity when issuing the action.
