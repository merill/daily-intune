Compare Windows Autopilot device preparation and Windows Autopilot

27 August 2026Doc update+5 / −4 lines

In brief

The comparison now documents that device preparation devices can be associated with a tenant before enrollment, while Windows Autopilot devices can be registered. It also updates the explanation of deployment selection for Autopilot-registered devices.

What Intune admins need to know

Admins can use the updated comparison to understand pre-enrollment device binding and how deployment selection is described.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
