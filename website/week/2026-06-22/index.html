Week in brief

Intune’s upcoming iOS/iPadOS 18 and macOS 15 support floors demand planning

The period is dominated by documentation maintenance: 561 of 568 records are updates, and representative diffs largely normalize admin-center links, punctuation, and wording. The substantive exceptions are two Message Center plan-for-change notices for Apple platform support, Enterprise App Catalog auto-update guidance, a Windows 25H2 security-baseline setting, and Microsoft 365 Apps baseline version 2512. Two new Trustd Mobile articles add integration and setup guidance, but the supplied evidence does not establish a launch, preview, or general-availability announcement.

  • Intune · App management
    Planned support change: iOS/iPadOS 18 becomes Intune’s minimum

    After Apple’s iOS/iPadOS 27 release later this year, Intune will require iOS/iPadOS 18 or higher. The notice directs organizations to use Intune compatibility checks and reports to identify affected devices; userless devices enrolled through Automated Device Enrollment have different OS-version requirements.

  • Intune · Device enrollment
    Planned support change: macOS 15 becomes the new enrollment floor

    After Apple’s macOS Golden Gate 27 release this year, Intune will support macOS 15 and later. Devices already enrolled on macOS 14.x or below remain enrolled, but new enrollments on those versions will no longer be allowed.

  • Enterprise App Management · App management
    Capability guidance: Enterprise App Catalog auto-update is assignment-scoped

    Updated Enterprise App Management guidance documents automatic updates for Enterprise App Catalog apps with a Required assignment. Intune detects newer catalog versions and updates targeted devices without requiring a new app or per-update supersedence relationship. The scope is Windows 10 and Windows 11 catalog apps; apps assigned Available for enrolled devices retain the existing workflow, while Guided update supersedence remains an alternative.

  • Intune · Device security
    Changed baseline behavior: Windows 25H2 adds IE11 COM automation blocking

    The June 2026 service update added Disable Internet Explorer 11 Launch Via COM Automation to the version 25H2 Windows security baseline with a default of Enabled. Profiles created before the update do not apply the setting automatically: administrators must edit and save them, after which Intune deploys the change at the next device check-in. New or updated version 25H2 profiles include it by default.

  • Intune · Device security
    Security baseline update: Microsoft 365 Apps version 2512 replaces 2306

    The Intune reference now documents Microsoft 365 Apps for Enterprise security baseline version 2512, first made available in June 2026, replacing version 2306. Listed defaults include Block Flash activation in Office documents = Enabled, Restrict legacy JScript execution for Office = Enabled, and Allow Trusted Locations on the network = Disabled. The article directs administrators to the Security Compliance Toolkit for the full 2512 settings.

For Intune administrators

Use Intune inventory and reports to identify iOS/iPadOS devices below version 18 and macOS devices on 14.x or below, then plan upgrades before Apple’s respective releases. Treat userless ADE devices separately because their iOS requirements differ. Review which Required Enterprise App Catalog assignments should use auto-update; Available assignments retain the existing workflow. For Windows 25H2 baseline profiles created before the June update, edit and save the profile so the new setting deploys at the next device check-in. If you use the Microsoft 365 Apps baseline, review version 2512 and its documented defaults before changing baseline plans.
