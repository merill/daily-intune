Day in brief

Windows 11 26H2 baseline settings and GCCH Remote Help guidance lead Intune updates

Intune’s most consequential update documents the Windows 11 version 26H2 security baseline, including Settings Catalog support, new settings, updated defaults, and revised guidance. Existing baseline profiles do not update automatically. The period also records Remote Help availability in US Government Community Cloud High for Android and Windows, clarifies Defender for Endpoint connector behavior on Android COBO and COPE devices, and previews a November 2026 Purview DLP and Intune approval workflow improvement. Configuration Manager 2609 guidance records a significant Windows Server client-support cutoff.

  • Intune · General
    26H2 security baseline guidance requires explicit profile action

    Intune now documents the Windows 11 version 26H2 security baseline and Settings Catalog support, including new settings, updated defaults, and revised guidance. Existing security baseline profiles do not update automatically; administrators adopting 26H2 must create a new profile or update an existing one.

  • Intune · Device security
    Defender for Endpoint setup documents Android COBO and COPE behavior

    The connector guidance states that enabling the Defender for Endpoint toggle automatically launches the app during setup on Android COBO and COPE devices. Grant MTD role permissions must also be enabled.

  • Intune · Apple
    Remote Help is available in GCCH for Android and Windows

    Intune guidance now states that Remote Help is available in US Government Community Cloud High environments for Android and Windows devices, enabling GCCH IT support staff to provide real-time troubleshooting with role-based access controls and Microsoft Entra ID sign-in.

  • Intune · App management
    Purview DLP will add Intune multi-admin approval for Edge unmanaged apps

    Starting November 2026, Microsoft Purview DLP will improve setup and support Intune multi-admin approval for unmanaged apps in Edge for Business, with clearer status, detailed errors, and task coordination between Purview and Intune administrators. Existing policies and enforcement will not change.

  • Configuration Manager · General
    Configuration Manager 2609 drops legacy Windows Server client support

    Configuration Manager version 2609 no longer supports Windows Server 2012, Windows Server 2012 R2, or their Windows Storage Server editions as client operating systems. Affected devices must be moved to a supported Windows Server version.
