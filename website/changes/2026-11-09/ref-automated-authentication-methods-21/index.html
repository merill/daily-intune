Device enrollment

Ref Automated Authentication Methods

9 November 2026Doc updateAction required+29 / −27 lines

In brief

The article now explicitly directs administrators to use Option 2: Setup Assistant with modern authentication for successful automated enrollments involving account-driven Apple User Enrollment. It also clarifies Company Portal, MFA, and phishing-resistant MFA guidance.

What Intune admins need to know

For affected enrollments, configure Setup Assistant with modern authentication; the other authentication method blocks enrollment for targeted users.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
