Intune security baseline overview

Each securityconfiguration baseline is a group of preconfigured Windows settings that help you apply and enforce granular security settings that the relevant security teams recommend. You can also customize each configuration baseline you deploy to enforce only those settings and values you require. When you create a securityconfiguration baseline profile in Intune, you're creating a template that consists of multiple device configuration profiles.

Intune also offers audit-only baselines, including Center for Internet Security (CIS) auditing in public preview. Audit-only profiles assess device configurations without changing settings. For prerequisites, profile creation, and reporting, see the CIS auditing guide (preview) or Security Technical Implementation Guide (STIG) auditing guide.

The settings in each baseline are device configuration settings like those found in various Intune policies. Each setting in a baseline works with the configuration service provider for the relevant product that is present on a managed windows device.

Available security baselines

The following security baseline instances are available for use with Intune. Use the links to view the settings or audit guidance for recent instances of each baseline.

  • Security Baseline for Windows 10 and later:

    • Version 26H2 Note

    The STIG audit baseline is available only for US Government Community Cloud High (GCC High) tenants and requires Advanced Analytics licensing.

  • CIS Audit Baseline (preview):

    • CIS Microsoft Intune for Windows 11 Benchmark (Audit Only) - Version 5.0.0

    The Center for Internet Security (CIS) audit baseline assesses Windows 11 device configurations without changing them. The public preview requires Intune Advanced Analytics. For profile creation, results, and export steps, see Audit Windows devices against CIS benchmarks.

When a new version for a configuration profile becomes available, settings in profiles based on the older versions become read-only. You can continue to use those older profiles. You can also edit the profile names, description, and assignments, but they don't support a change to their settings configuration and you can't create new profiles based on the older versions.

When you're ready to use the more recent baseline version, you can create new profiles or update your existing profiles to the new version. See Update a baseline profile to the latest version in the Manage security baseline profiles article.

Strictly speaking, no. The Microsoft security team consults organizations, such as CIS, to compile its recommendations. However, there isn't a one-to-one mapping between "CIS-compliant" and Microsoft baselines.

To assess device configurations against the supported CIS benchmark instead of deploying a Microsoft-recommended configuration baseline, use the CIS audit baseline (preview). Auditing identifies configuration gaps; it doesn't configure settings or certify compliance.

What certifications do Microsoft's security baselines have?

Microsoft continues to publish security baselines for group policies (GPOs) and the Security Compliance Toolkit, as it has for many years. These baselines are used by many organizations. The recommendations in these baselines are from the Microsoft security team's engagement with enterprise customers and external agencies, including the Department of Defense (DoD), National Institute of Standards and Technology (NIST), and more. We share our recommendations and baselines with these organizations. These organizations also have their own recommendations that closely mirror Microsoft's recommendations. As mobile device management (MDM) continues to grow into the cloud, Microsoft created equivalent MDM recommendations of these group policy baselines. Many of these baselines are built into Microsoft Intune, and include compliance reports on users, groups, and devices that follow (or don't follow) the baseline.
