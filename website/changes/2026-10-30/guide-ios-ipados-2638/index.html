Device enrollment

Guide Ios Ipados

30 October 2026Retirement+17 / −25 lines

In brief

Intune ended support for Setup Assistant (legacy) authentication for Automated Device Enrollment with user affinity in the October 2026 (2610) service release. Existing profiles are automatically updated to Setup Assistant with modern authentication, and the documentation now recommends modern authentication with JIT registration.

What Intune admins need to know

Review enrollment profiles and user authentication flows because legacy authentication is no longer available; existing profiles are updated automatically.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
