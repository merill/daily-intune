Day in brief

Configuration Manager 2603 hotfix fixes Connected Cache for Intune Win32 apps

The period’s clearest operational change is a Configuration Manager 2603 hotfix for Connected Cache failures affecting Intune-deployed Win32 apps in co-managed environments. Other meaningful guidance covers replacing expiring Cloud PKI issuing CAs, HTTPS and role constraints for HSTS, and default-enabled Copilot capabilities in Edge for mobile. Most remaining updates are link, metadata, formatting, or navigation maintenance.

  • Configuration Manager · General
    Configuration Manager 2603 Connected Cache hotfix targets Intune Win32 delivery

    New 2603 guidance addresses Microsoft Connected Cache not being used as expected for Win32 apps deployed through Intune in co-managed environments. It provides DoincInstall.exe version 1.5.5.9002; install the hotfix on all site servers and reset MCC on affected distribution points by disabling and re-enabling MCC or using resetdps.trn for large deployments.

  • Cloud PKI · General
    Cloud PKI expiration guidance specifies replacement CA and SCEP updates

    The updated article directs administrators to create a replacement issuing CA and replace the old SCEP URI in every affected SCEP certificate profile before the existing CA expires, avoiding an interruption to new certificate issuance.

  • Configuration Manager · General
    HSTS guidance ties Configuration Manager deployment to HTTPS and role compatibility

    The documentation states that HSTS requires HTTPS, is incompatible with Enhanced HTTP, is unsupported for client communication, and can break HTTP-dependent roles such as FSP and SUP. Before configuring HSTS, administrators must enable HTTPS and verify that affected site-system roles do not rely on HTTP.

  • Intune · App management
    Edge mobile guidance records default-enabled Copilot chat and browsing context

    The Manage Microsoft Edge page now states that M365 Copilot chat is available on Edge for iOS and Android, enabled by default, and launched from the address bar. Browsing-context access is also enabled by default; administrators can review the Chat and ChatPageContext policies when they need to control these capabilities.
