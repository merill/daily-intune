Week in brief

Endpoint Privilege Management support for AVD single-session remains in development

The clearest service-status signal is that Intune Endpoint Privilege Management (EPM) support for users on Azure Virtual Desktop single-session virtual machines is described as being added, with no availability date or general-availability claim. The rest of the supplied evidence is overwhelmingly documentation work: five new Apple configuration pages cover custom settings, device features, restrictions, VPN, and Wi-Fi; Windows Autopilot marks a device-preparation known issue resolved in February 2026; and Remote Help adds a notification-policy troubleshooting condition. Of 248 changes, 243 were updates and no Message Center items were supplied. Several Apple enrollment pages also move links from iOS-only references to Apple-wide restriction and device-feature pages, which is navigation maintenance rather than a reported settings change.

  • Intune · Fundamentals
    EPM on AVD single-session is an in-development capability, not a dated release

    The Intune in-development page says Microsoft is adding support to deploy Endpoint Privilege Management policies to users on Azure Virtual Desktop single-session virtual machines. It says EPM elevation policies will work in that environment when the support becomes available, and identifies EPM as an Intune Suite add-on capability. No availability date or general-availability status is provided.

  • Intune · Apple
    Custom Apple profiles get explicit prerequisites and sensitive-data guidance

    A new Intune article documents custom profiles for iOS/iPadOS and macOS to add settings and features that are not built into Intune. It lists the minimum Policy and Profile Manager RBAC role. Its displayed device-configuration prerequisite is to create a VPN device configuration profile. The article also says not to use custom profiles for sensitive information such as Wi-Fi connections or authenticating apps; it directs administrators to built-in Wi-Fi and certificate profiles instead.   • Intune · Apple
    Apple device features reference records a one-profile AirPrint limitation

    The new Device Features reference covers iOS/iPadOS and macOS features including AirPrint, home screen layout, notifications, shared devices, single sign-on, and web content filtering. It explicitly says to add all printers to the same profile because Apple prevents multiple AirPrint profiles from targeting the same device. The page also identifies the Policy and Profile Manager RBAC role and a device-features configuration profile as prerequisites. This is reference guidance, not evidence of a feature release.

  • Windows Autopilot · Device enrollment
    Windows Autopilot marks a device-preparation known issue resolved

    The Windows Autopilot known-issues page changed its date from November 10, 2025, to February 5, 2026, added “Date updated: February 5, 2026,” and states, “This issue was resolved in February 2026.” The supplied diff does not identify the issue or prescribe a configuration change, so affected deployment teams should validate their previously impacted workflow rather than alter Autopilot broadly.

  • Remote Help · Endpoint analytics
    Remote Help adds notification blocking to its troubleshooting path

    A new troubleshooting row identifies “The device has blocked applications from using notifications” and points administrators to Policy CSP - Notifications, specifically the disallowcloudnotification setting. This clarifies diagnosis for that symptom; it does not document a change to Remote Help policy behavior.

For Intune administrators

Do not plan on EPM support for AVD single-session as generally available; the in-development text provides no release date. Apple administrators should review the new profile guidance before using custom profiles: it says not to place sensitive Wi-Fi or authentication information in custom profiles and to use built-in Wi-Fi and certificate profiles instead. The Apple Device Features reference also says all AirPrint printers must be placed in one profile. Autopilot teams tracking the resolved known issue can update runbooks and retest, but the supplied diff does not identify the issue. Remote Help administrators need to consult Policy CSP - Notifications only when the notification-blocking symptom occurs.
