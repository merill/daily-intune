Week in brief

CIS Windows 11 audits lead Intune’s Server pilot and 2027 Company Portal deadline

The week’s strongest Intune developments are a non-remediating CIS Windows 11 audit workflow, a constrained Windows Server Insider Preview pilot path, and managed Google Workspace authentication guidance for Android Enterprise. Remote Help guidance also covers consent-based diagnostic sharing, while a Message Center notice sets a February 2027 Company Portal minimum-version deadline. Most other entries are editorial, reference, or procedural clarifications, with separate Autopilot and Configuration Manager troubleshooting updates.

  • Intune · Device security
    CIS audit profile assesses 404 Windows 11 settings without remediation

    The new Intune guidance documents a CIS Microsoft Intune for Windows 11 Benchmark audit profile covering Level 1, Level 2, and BitLocker checks across 404 settings. It reports findings, supports result review and export, and does not configure or remediate devices. Use requires Advanced Analytics, enrolled Windows 11 devices, and appropriate Intune permissions.

  • Intune · Device enrollment
    Windows Server Insider Preview gets a nonproduction Intune pilot guide

    Microsoft added an end-to-end guide for piloting supported Windows Server Insider Preview vNext builds in Intune, covering enrollment, configuration, compliance, apps, updates, verification, prerequisites, and supported server types. Server Core is not supported, and the documented scenario is for testing and evaluation rather than production use.

  • Intune · Android
    Android Enterprise gains ownership-specific Google Workspace sign-in guidance

    A new Intune article explains how to require managed Google Account authentication on supported corporate-owned and personally owned Android Enterprise devices. It covers prerequisites, enrollment types, policy creation, and assignment, allowing administrators to choose the applicable profile method for each ownership type.

  • Remote Help · Troubleshooting
    Remote Help guidance covers consent-based diagnostic sharing

    Helpers can request permission to view and possibly store a sharer’s device diagnostic data. With consent, both participants can view the report, and the helper can refresh it during troubleshooting. Reports include device, hardware, network, performance, security, update, storage, and peripheral details.

  • Intune · Device enrollment
    Company Portal minimum version rises to v5.2608.0 in February 2027

    Starting in February 2027, the minimum iOS/iPadOS and macOS Company Portal version will be v5.2608.0. Most users update automatically, but users in environments that block app installation may need a manual update.

For Intune administrators

Use the CIS profile for assessment rather than remediation, keep Windows Server Insider testing in nonproduction, and select the Android authentication policy path that matches device ownership. Prepare iOS/iPadOS and macOS Company Portal deployments for version 5.2608.0 before February 2027, especially where app installation is restricted. Remote Help diagnostic access remains subject to the sharer’s consent.
