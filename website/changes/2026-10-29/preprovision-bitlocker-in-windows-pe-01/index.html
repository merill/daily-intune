Preprovision Bitlocker In Windows Pe

29 October 2026Feature updateAction required+10 / −8 lines

In brief

The documentation replaces Windows 7-specific instructions with Windows guidance, updates the boot image requirement to a supported ADK and Configuration Manager client version, and clarifies when to restart in Windows PE.

What Intune admins need to know

Verify that task sequences use a supported ADK boot image and updated Configuration Manager client version.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.

Applies to: Configuration Manager (current branch)

The Pre-provision BitLocker task sequence step in Configuration Manager allows you to enable BitLocker from the Windows Preinstallation Environment (Windows PE) prior to operating system deployment. Only the used drive space is encrypted, and therefore, encryption times are much faster. This is done with a randomly generated clear protector applied to the formatted volume and encrypting the volume prior to running the Windows setup process. The ability to pre-provision BitLocker was introduced withonly applies to currently supported Windows 8 and Windows Server 2012. However, you can pre-provision BitLocker on a hard drive and install Windows 7 as long as you follow specific steps. After Windows 7 Setup completes, you must set a BitLocker key protector because the Windows 7 BitLocker control panel does not support BitLocker with a clear protector. You must add a key protector by using the Enable BitLocker step or by using the manage-bde.exe command-line tool.operating system versions.
