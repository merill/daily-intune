Plan for Change: Removal of legacy Apple MDM software updates

11 September 2026MC1470869 on mc.merill.net ↗Message

In brief

Apple has ended support for legacy MDM software update commands with OS 27. Intune will remove the legacy update UI in its October release. Admins must switch to declarative device management (DDM) for Apple software updates to ensure devices continue updating properly. Review and update policies accordingly.

Message Center announcement

As previously announced, Apple ended support for legacy mobile device management (MDM) software update commands with OS 26 and Intune also ended support soon after the release. Apple has removed these settings and commands with the release of OS 27.

Starting with Intune's October (2610) service release, we will remove the associated legacy software update UI from the Intune admin center. For supported Apple software update workflows, we recommend moving to declarative device management (DDM) software update settings. For more details, refer to Support tip: Move to declarative device management for Apple software updates

How this will affect your organization:

After this change, admins will no longer be able to use the legacy UI for the affected Apple software update policies and reporting experiences in the Intune admin center. If you do not update your policies to use DDM, the devices may fail to update after this change.

This change affects the following legacy MDM software update experiences:

  • iOS/iPadOS update policies
  • macOS update policies
  • Software update settings in the iOS/iPadOS and macOS Device restrictions templates
  • Software settings for iOS/iPadOS and macOS in the settings catalog under 'Restrictions'
  • Software payload settings for macOS in the settings catalog
  • Per-device macOS software updates report
  • iOS/iPadOS update installation failures report
  • macOS update installation failures report

Supported Apple software update management is available through declarative device management (DDM) settings in Intune.

What you need to do to prepare:

Review your existing iOS/iPadOS and macOS software update workflows and move to DDM-based software update management before the legacy UI is removed. If you enforce DDM software update policies, devices use the DDM update settings rather than legacy MDM update settings.

Review Managed software updates in the settings catalog and the blog for moving to declarative device management for Apple software updates.

Additional information:

  • Configure update policies for Apple devices | Microsoft Learn
  • Apple WWDC information about legacy MDM software update commands
