Week in brief

Vulnerability Remediation Agent licensing and Remote Help role prerequisites sharpen Intune guidance

The strongest edits clarify documented prerequisites for Security Copilot’s Vulnerability Remediation Agent, Intune custom roles, and Windows Remote Help sign-in. Additional Intune guidance replaces an Incident ID with log-collection status and removes one Diagnostic Endpoint from the prerequisites list.

  • Security Copilot · Troubleshooting
    Agentic user licensing and tenant-setting prerequisite

    The Vulnerability Remediation Agent guidance now says the agentic user must have an Intune license unless Tenant administration > Roles > Settings has Allow admins without an Intune license enabled. Check this prerequisite before relying on the agent.

  • Intune · Fundamentals
    Custom roles separate Android control from Windows remote sign-in

    The custom-role guidance distinguishes Android unattended control, which requires a dedicated Intune-enrolled device, from Windows unattended remote sign-in for targeted physical corporate-owned devices. Both permissions must be explicitly assigned and scoped.

  • Intune · Fundamentals
    Remote Help Windows sign-in points to AVD session-host endpoints

    Network endpoint guidance now says Remote Sign-in for Remote Help on Windows requires Azure Virtual Desktop session host endpoints. Administrators using unattended access should verify that these endpoints are permitted in their network configuration.

  • Intune · Device security
    Monitor replaces Incident ID with collection status

    The Monitor guidance now lists log collection as completed, failed, or in progress instead of showing an Incident ID. It also says Microsoft can use logs collected after reproducing an issue during verbose log collection for investigation.

  • Intune · Device security
    Prerequisites removes one Diagnostic Endpoint

    The prerequisites page no longer lists `powerlift-frontdesk.acompli.net` as a Diagnostic Endpoint. Update local Microsoft Tunnel log collection notes that still include this endpoint.

For Intune administrators

Review agent licensing and the tenant exception setting, reassess custom-role permissions and scopes, and verify Azure Virtual Desktop session-host endpoints for applicable Remote Help deployments. Update troubleshooting procedures to use collection status and remove the deleted endpoint from local prerequisite notes where applicable.
