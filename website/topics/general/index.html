Latest General changes

12 November 2026

12709700

General

The documentation now details an issue where multiple required versions of an extension can repeatedly prompt installation and prevent the Configuration Manager console from opening. It adds a SQL workaround for previous versions.

12 November 2026

2377842

General

The documentation now states that the 2609 update was unpublished on November 11, 2026, because of an issue that can unexpectedly remove discovery data for Active Directory and Microsoft Entra ID groups, affecting collection membership. Release history was also added.

12 November 2026

Index

General

Intune documentation adds eScription One, Prisma Browser for Intune, and Elevate UC for Intune to the available protected apps list.

12 November 2026

Release Notes

General

The release notes now document that ODBC Driver 18.7.1.1 can block site configuration on Configuration Manager 2603 and earlier during an upgrade to version 2609. They recommend using validated driver version 18.6.2.1 instead.

9 November 2026

Bulk registration token verification fails after installing Configuration Manager 2603 update rollup - Configuration Manager | Microsoft Learn

General

KB40345593 fixes bulk registration token verification failures for non-Microsoft Entra-joined devices connecting through a CMG after KB39169655 is installed.

9 November 2026

Tutorial Co Manage New Devices

General

The documentation now uses present-tense wording for enabling co-management, clarifies use of the saved enablement command, and simplifies the pilot collection instruction. The supported Azure clouds remain unchanged.

7 November 2026

Recover Sites

General

The procedure now says to delete only Configuration Manager entries from the Services registry key and explicitly excludes SMSvcHost entries, which belong to .NET Framework.

6 November 2026

Checklist for 2609 - Configuration Manager | Microsoft Learn

General

The checklist now states that version 2609 automatically disables shared-key access for CMG storage and adds prerequisites for existing CMGs, including service-principal role-assignment permissions and Microsoft.Maintenance registration.

6 November 2026

CMG security and privacy - Configuration Manager | Microsoft Learn

General

The documentation now states that shared-key access is automatically disabled for CMG storage starting in Configuration Manager version 2609, including existing deployments. It also adds required permissions for Microsoft Entra-authenticated storage and clarifies that storage keys and application secrets are separate credentials.

6 November 2026

Configure Microsoft Entra ID for CMG - Configuration Manager | Microsoft Learn

General

Starting in version 2609, CMG storage shared-key access is disabled. The CMG server application now requires permissions to manage storage role assignments, and Microsoft.Maintenance must be registered for the subscription.

6 November 2026

What's new in version 2609 - Configuration Manager | Microsoft Learn

General

The version 2609 documentation now instructs administrators to verify the CMG server application's Azure role-assignment permissions at the CMG resource group and ensure Microsoft.Maintenance is registered in the subscription before updating a site with a CMG.
