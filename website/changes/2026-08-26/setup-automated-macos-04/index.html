Setup Automated Macos

26 August 2026Feature update+4 / −3 lines

In brief

The macOS setup documentation now lists the Liquid Glass pane as skippable for macOS 27.0 and later.

What Intune admins need to know

Administrators can account for this pane when configuring macOS enrollment profiles; no required action is stated.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
