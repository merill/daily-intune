Device enrollment

Whats New

30 October 2026New feature+11 / −1 lines

In brief

Intune Enterprise App Management auto-update apps can now be selected as blocking apps in an Enrollment Status Page profile. Device setup remains blocked until the selected apps are installed.

What Intune admins need to know

Administrators can use this to help ensure required EAM apps are available before users access the desktop.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.

Block on Enterprise App Management auto-update apps during the Enrollment Status Page

Date added: October 29, 2026

You can now select Microsoft Intune Enterprise App Management (EAM) auto-update apps as blocking apps in an Enrollment Status Page (ESP) profile. ESP blocks device setup until the selected apps are installed, helping ensure required apps are available before users access the desktop.

For related information, see Add an Enterprise App Catalog app to Microsoft Intune.
