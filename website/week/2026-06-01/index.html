Week in brief

CMG image deprecation drives Configuration Manager’s Windows Server 2022 transition

Configuration Manager’s CMG VMSS update is the week’s most consequential change: gateways are moving from the legacy Windows Server 2022 Azure Marketplace offer `windowsserver`, which includes .NET 6, to `windowsserver2022`. The legacy images will lose support and image-refresh OS updates, and new CMG deployments or reimaging will fail when enforcement begins in early 2027. Intune’s substantive changes were more focused: Local AI Agent/OpenClaw inventory guidance became more specific, Apple wired-network documentation now covers iOS/iPadOS as well as macOS, and the GCC High/DoD matrix distinguishes available Windows Autopilot device preparation from unsupported update capabilities. Most other edits were documentation maintenance; the dedicated Multi Admin Approval Graph API article was removed, while Remote Help references show differing version numbers rather than a new capability.

  • Configuration Manager · General
    CMG VMSS update replaces legacy Windows Server 2022 images

    KB37942646 transitions the CMG virtual machine scale set from Azure Marketplace offer `windowsserver`, which includes .NET 6, to `windowsserver2022`, which does not. Legacy images will no longer be supported or receive new OS patch updates through image refresh; once enforcement begins in early 2027, new CMG deployments and reimaging operations that use them will fail. The update is available through Updates and Servicing for Configuration Manager 2603 and for 2503/2409 with the required rollups; 2509 includes itใน

  • Intune · Windows
    Properties Catalog guidance sharpens Local AI Agent discovery

    The Windows Properties Catalog reference lists Agent Name, Install Location, Install Scope, and Host process for Local AI Agent inventory. Microsoft recommends collecting Host process because OpenClaw can run under process names such as `node.exe` or `wsl.exe`. The linked security baseline label also changed from “Local AI Agent Baseline - OpenClaw (Preview)” to “Local AI Agent Baseline - OpenClaw”; that terminology change alone does not establish general availability.

  • Intune · Apple
    Apple wired-network reference expands documented scope to iOS/iPadOS

    The wired-network settings article changed from macOS-only wording to Apple devices and now explicitly covers iOS/iPadOS and macOS, with platform-specific sections and prerequisites. It states that the settings are available for all enrollment types and requires a wired network device configuration profile with the minimum Policy and Profile Manager role. The supplied diff establishes a documentation scope and prerequisite change, not a separate rollout announcement.

  • Intune · Android
    GCC High and DoD matrix marks Autopilot preparation available

    The government service table now marks Windows Autopilot device preparation as available and identifies user-driven deployments as available, while other device-preparation features remain in planning. The unavailable list separately names Windows Autopatch, Feature updates, Quality updates, Expedite updates, and Driver updates for GCC High and DoD. Government administrators should distinguish the available user-driven path from planned functionality.

  • Intune · Fundamentals
    Multi Admin Approval Graph API guidance is retired from Learn

    The dedicated “Use Multi Admin Approval with the Microsoft Graph API” article was removed. Its former guidance described opt-in access policies, interception of app-authenticated calls that modify protected Intune resources, HTTP 403 responses when required approval headers were missing, and no impact on read-only GET operations. This is a documentation retirement; the diff does not establish that MAA or app-auth enforcement was retired.

For Intune administrators

Configuration Manager administrators should review CMG VMSS deployments and install KB37942646 through Updates and Servicing where applicable. It applies directly to versions 2603 and 2509, and to versions 2503 and 2409 with the required rollups; the 2509 second update rollup already includes it. CMG timing language changed during the week: an initial KB37784287 entry cited June 9, 2026, while later wording cites enforcement in early 2027, so validate the applicable current guidance before scheduling. Intune administrators collecting device properties should consider the recommended Host process field for OpenClaw discovery.
