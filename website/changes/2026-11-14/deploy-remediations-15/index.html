About Remediations

Remediations are script packages that can detect and fix common support issues on a user's device before theyusers even realize there's a problem. Remediations can help reduce support calls and tickets. You can create your own script package or deploy a built-in script package.

Each script package consists of a detection script, a remediation script, and metadata. When you use Intune, you can deploy these script packages and see reports on their effectiveness.
