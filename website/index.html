Day in brief

Android local actions and Windows maintenance windows get new Intune setup guidance

The period was dominated by documentation maintenance, but two new how-to pages add useful operational guidance: Android local actions for event-driven kiosk behavior and Windows maintenance windows for scheduled update activity. Existing guidance also adds more precise Windows Update ring settings and a workaround for a possible iOS/iPadOS enrollment failure.

  • Intune · Android
    Android local actions are documented for event-driven device and kiosk workflows

    The new guidance covers Local actions profiles for dedicated and fully managed Android Enterprise devices. Events include device reboots, Managed Home Screen sign-ins, and power-connection changes; available actions include launching apps, sending broadcasts, signing users out, and exiting kiosk mode. Activity actions require Overlay Permission granted through OEMConfig.

  • Intune · Device updates
    Windows maintenance-window guidance specifies update scheduling limits and prerequisites

    The new page explains one-time and recurring windows that control when automatic Windows Update downloads, installations, and update-related restarts can begin. Schedules use device local time. The documented prerequisite is Windows 11 version 24H2 with KB5077181 and build 26100.7840 or later; the guidance calls for testing on representative devices before broad assignment.

  • Intune · Device updates
    Update Ring Settings guidance now separates quality and feature update controls

    The reference page now documents deadline, grace-period, and automatic-reboot settings separately for quality and feature updates, with related CSP references. It also recommends short quality-update deferrals and appropriate grace periods, giving administrators more specific guidance for configuring restart behavior.

  • Intune · Device enrollment
    iOS/iPadOS enrollment troubleshooting adds a sync workaround for Entra join failure

    The enrollment guide now covers a possible one-time Microsoft Entra ID join failure. A manual device sync is documented as resolving the issue for future enrollments, with adding the Microsoft Intune Certificate Authority client production app provided as an alternative workaround.
