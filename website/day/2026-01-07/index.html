Day in brief

Windows Driver updates guidance now documents Autopatch licensing and cloud limits

The period is dominated by a coordinated rewrite of Intune’s Windows Driver updates material rather than broad feature announcements. A new policy reference covers review, approval, automatic deployment, pausing, and manual management, while related guidance spells out cloud, licensing, Windows-edition, and government-environment boundaries. Other substantive documentation changes classify Hotpatch within Quality updates, state that Intune audit logs are retained for up to two years, and remove the old driver FAQ; most remaining edits are link, title, navigation, formatting, or wording maintenance.

  • Intune · Device updates
    Driver Updates gets a new policy-management reference

    A new Intune page describes how administrators can review, approve, automatically deploy, pause, or manually manage Windows driver updates, and includes licensing, supported Windows-edition, and deployment-behavior guidance.

  • Intune · Device updates
    Driver Updates documentation specifies tenant and license boundaries

    The Driver Updates article says policies are supported only in the public cloud and require Intune Plan 1 plus a Windows license with the Autopatch entitlement. GCC High and DoD environments are not supported, and LTSC remains unsupported.

  • Intune · Device updates
    Hotpatch is grouped under Quality updates in the update index

    The Device updates index now describes Autopatch without naming WUfB DS, places Hotpatch under Quality updates, and includes Feature, Quality, and Driver updates in its Microsoft Entra registered-device limitation. It also describes Hotpatch as optional for manual quality-update management and automatic for eligible Autopatch devices.

  • Intune · Device security
    Intune audit-log retention is stated as up to two years

    The Privacy Data Store Process page now states that Intune audit logs are retained for up to two years for security purposes, giving administrators an explicit retention period for audit-data handling.

  • Intune · Device updates
    Windows Driver updates FAQ is removed

    The removed FAQ covered assignment filters, Autopilot, rollback, policy assignments, reboots, driver availability, and Windows Autopatch synchronization. Administrators can no longer use that page as a reference for those policy questions.
