Latest Microsoft Configuration Manager changes

21 August 2026

Windows Antivirus policy settings from Microsoft Defender Antivirus for tenant attached devices

Device security

The documented default for catch-up full scans changed to disabled, while catch-up quick scans remain enabled by default. The settings now specify that catch-up scans occur after two consecutive missed scheduled scans and require a configured scheduled scan.

20 August 2026

Levels of diagnostic usage data

Fundamentals

The documentation replaces version-specific diagnostic and usage data links with one consolidated article, stating that collection is consistent across supported current branch versions.

20 August 2026

Levels Of Diagnostic Usage Data Collection 2509

Troubleshooting

The 737-line reference page detailing Configuration Manager version 2509 diagnostic and usage data was deleted as part of consolidating information for supported current branch versions.

18 August 2026

Migrate from MBAM

Device security

The documentation now explains how to retrieve existing MBAM groups with PowerShell and map them to equivalent Configuration Manager BitLocker portal groups during migration.

7 August 2026

Azure Virtual Desktop

Fundamentals

The documentation now states that deployment must use an Azure subscription associated with the same Entra ID tenant as Intune.

7 August 2026

Boundary Groups Software Update Points

General

The documentation now refers to the CMG SUP server instead of the CGM SUP server when describing boundary group configuration.

7 August 2026

Manually register Microsoft Entra apps

General

The guide no longer instructs administrators to set `oauth2AllowIdTokenImplicitFlow` to `true` in the app manifest. The page date was also updated.

7 August 2026

Software Center User Guide

Windows

The title capitalization was standardized, and the description now highlights installing apps, software updates, and Windows upgrades, plus the required Software Center setting.

7 August 2026

Use The Service Connection Tool

General

The service connection tool example adds port 8080 to the proxy server URI and updates the heading accordingly.

7 August 2026

What's new in version 2603

General

The page date was updated, and the SQL Server note now states that SQLSysClrTypes.msi and SharedManagementObjects.msi are no longer included. It also documents the move from deprecated SQL Server 2014 versions to SQL Server 2025 versions (SMO 17).

7 August 2026

Whats New In Version 2603

General

The documentation now clarifies that SQL Server Management Objects and SQL Server CLR Types use SQL Server 2025 versions (SMO 17), and that the related MSI files are no longer included in Configuration Manager media.
