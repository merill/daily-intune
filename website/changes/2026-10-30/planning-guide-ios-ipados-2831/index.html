Planning Guide Ios Ipados

30 October 2026Retirement+28 / −39 lines

In brief

The documentation states that Apple deprecated MDM-based software update workloads and removed related commands with OS 27. It now directs administrators to Software Update enforcement and Software Update Settings, with enforcement based on each device’s local time zone.

What Intune admins need to know

Administrators should plan to use DDM-based update controls and review policies that rely on UTC scheduling or legacy MDM software update workloads.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
