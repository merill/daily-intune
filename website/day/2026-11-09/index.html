Day in brief

Configuration Manager 2603 sites with KB39169655 need KB40345593

The period’s clearest operational item is a new Configuration Manager fix for bulk registration token failures through a CMG. Intune also tightened the documented authentication path for account-driven Apple User Enrollment. Most remaining entries revise Autopilot, Intune, and Configuration Manager procedures, terminology, navigation, or metadata; the revised Autopilot existing-device instructions contain one concrete procedural change.

  • Configuration Manager · General
    Configuration Manager documents the 2603 CMG token-verification fix

    KB40345593 fixes bulk registration token verification failures for non-Microsoft Entra-joined devices connecting through a cloud management gateway after KB39169655 is installed. For affected version 2603 sites, install it from Updates and Servicing; a site reset is required, existing secondary sites must be updated manually, and no computer restart is required.

  • Intune · Device enrollment
    Intune directs account-driven Apple enrollments to modern authentication

    The automated authentication guidance now explicitly directs administrators to use Option 2, Setup Assistant with modern authentication, for successful account-driven Apple User Enrollment. The other authentication method blocks enrollment for targeted users; the page also clarifies Company Portal, MFA, and phishing-resistant MFA guidance.

  • Windows Autopilot · Device enrollment
    Autopilot existing-device instructions change the Enrollment Status Page path

    The revised procedure separates selecting Windows from navigating to Windows Autopilot > Enrollment Status Page, and the previous automatic-enrollment step is no longer included. Administrators consulting the article should follow the updated navigation.
