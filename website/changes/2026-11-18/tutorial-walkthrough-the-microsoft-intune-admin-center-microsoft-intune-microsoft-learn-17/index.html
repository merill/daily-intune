Tutorial - Walkthrough the Microsoft Intune Admin Center - Microsoft Intune | Microsoft Learn

Microsoft Intune provides the cloud infrastructure, the cloud-based mobile device management (MDM), cloud-based mobile application management (MAM), and cloud-based PC management for your organization. Intune helps you ensure that your company's devices, apps, and data meet your company's security requirements.

You have the control to set which requirements need to be checked and what happens when those requirements aren't met. The Microsoft Intune admin center is where you can find the Microsoft Intune service, as well as other device management related settings. Understanding the features available in Intune will helphelps you accomplish various Mobile Device Management (MDM) and Mobile Application Management (MAM) tasks.

Note

Microsoft Intune is a single, integrated endpoint management platform for managing all your endpoints. The Microsoft Intune admin center integrates Microsoft Configuration Manager and Microsoft Intune.
