Day in brief

Managed Home Screen gains two planned RBAC permissions in Intune’s February release

Intune’s most consequential item is a planned February RBAC change: TemporarilySuspendManagedHomeScreen and RestoreManagedHomeScreen will be added to the School Administrator and Help Desk Operator built-in roles. Documentation updates also clarify Windows Feature Updates licensing and support boundaries, identify Azure Virtual Desktop single-session VMs as an EPM-supported platform, extend the documented audit-log window to two years, and restate the required MDT removal sequence. A new Windows Driver updates FAQ centralizes guidance on filters, Autopilot, rollback, multiple policies, reboots, driver availability, and Autopatch synchronization. Much of the remaining activity was terminology, formatting, navigation, or procedural cleanup.

  • Intune · Tenant administration
    Managed Home Screen RBAC permissions are planned for February

    Intune’s February release adds TemporarilySuspendManagedHomeScreen and RestoreManagedHomeScreen to the School Administrator and Help Desk Operator built-in roles. Microsoft states that no administrator action is required, while reviewing role assignments and updating internal documentation is recommended.

  • Intune · Device updates
    Feature Updates guidance now sets licensing and support boundaries

    The guidance specifies Intune Plan 1 for core Feature Updates functionality and an Autopatch-entitled Windows license for gradual rollout and optional feature updates. It also identifies GCC High/DoD and LTSC scenarios that require alternative patching methods.

  • Intune · Device security
    EPM support guidance now names AVD single-session virtual machines

    The supported-platform list now directly names Azure Virtual Desktop single-session virtual machines and Windows 365 for Endpoint Privilege Management policies, giving administrators clearer scope when planning virtual deployments.

  • Intune · Device security
    Intune audit-log retention guidance now says up to two years

    The Privacy Data Store Process page now states that Intune audit logs are retained for up to two years for security purposes, instead of one year. Administrators should account for the longer documented availability in security and compliance processes.

  • Configuration Manager · General
    Configuration Manager documents the required MDT removal order

    The release notes instruct administrators to remove all MDT task sequence steps before removing MDT integration. MDT remains retired and unsupported, and following this order helps prevent task sequence corruption and modification failures.
