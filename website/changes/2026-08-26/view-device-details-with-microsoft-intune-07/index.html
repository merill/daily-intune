View device details with Microsoft Intune

26 August 2026Feature update+14 / −10 lines

In brief

The device details documentation now covers ICCID, EID, phone number, carrier, activation state, and SIM origin for supported Android Enterprise corporate-owned devices, including Android version requirements.

What Intune admins need to know

Administrators can use these fields to monitor and troubleshoot eSIM and SIM status on supported Android devices. No action is required.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
