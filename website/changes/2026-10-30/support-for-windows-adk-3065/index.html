Support For Windows Adk

30 October 2026Doc update+8 / −8 lines

In brief

The page date and wording were updated, including clearer statements about the ADK requirement, ARM64 deployments on Configuration Manager 2403 or later, and the BitLocker workaround for ADK 10.1.22000.

What Intune admins need to know

Administrators can use the revised guidance when checking ADK prerequisites and the applicable BitLocker workaround.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
