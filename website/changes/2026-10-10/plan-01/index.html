Microsoft Intune Remote Help
General

Plan

10 October 2026Doc update+1 / −0 lines

In brief

The Remote Help planning documentation now states that tenants in the Switzerland North datacenter region cannot use Windows unattended remote sign-in.

What Intune admins need to know

Administrators in this region should account for this limitation when planning Remote Help usage. No action is required by the update.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
