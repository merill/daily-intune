Setup Cloud Management Gateway

26 October 2026Doc update+4 / −4 lines

In brief

The setup instructions now link to VM sizing guidance by Configuration Manager version, capacity, and upgrade requirements. The Lab (B2s) size is now called the Small tier and remains intended only for lab or proof-of-concept use.

What Intune admins need to know

Review the updated sizing guidance when configuring a CMG and avoid using the Small tier for production.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
