Month in brief

Windows MDM-only CNAME retirement and CMG NAT migration set October’s endpoint agenda

October’s clearest operational deadlines are Intune’s January 15, 2027 end of DNS CNAME auto-discovery for Windows MDM-only enrollment and Configuration Manager’s September 30, 2027 cutoff for avoiding Azure Load Balancer inbound NAT rules version 1 in the 2603 rollup. Intune also planned the 2609 device page as the default view, added November 2026 Purview DLP and Intune approval coordination, and documented the Windows 11 26H2 baseline path. Much of the remaining activity was reference, link, metadata, or procedural maintenance rather than a broad feature rollout.

  • Intune · Device enrollment
    Intune will retire DNS CNAME auto-discovery for Windows MDM-only enrollment

    Starting January 15, 2027, affected users must enter the Microsoft enrollment server URL manually. Existing devices and other enrollment methods are unaffected, so the required preparation is to update enrollment procedures.

  • Configuration Manager · General
    Configuration Manager 2603’s rollup sets the CMG NAT v1 migration deadline

    KB39169655 documents CMG migration to a supported Windows Server 2022 image, Azure Load Balancer inbound NAT rules version 2, and newer VM sizes. Install it before September 30, 2027 to avoid inbound NAT rules version 1 retirement; check Azure capacity and vCPU quotas first, then upgrade the console.

  • Intune · General
    Windows 11 26H2 baseline guidance changes profile preparation

    Intune now documents the Windows 11 version 26H2 security baseline and Settings Catalog support, including new settings and updated defaults. Existing security baseline profiles do not update automatically; administrators must create a new profile or update an existing one to use the 26H2 baseline.

  • Intune · Endpoint analytics
    The 2609 Intune device page becomes default with explicit action permissions

    The new device page will become the default view with the September 2609 release, replacing the legacy page while retaining device-management features. Administrators need the Managed devices/Update permission plus specific action permissions, making RBAC review part of the transition.

  • Intune · App management
    Purview DLP will add Intune multi-admin approval for Edge unmanaged apps

    Starting in November 2026, the workflow will provide clearer status, detailed errors, and task coordination between Purview and Intune administrators for unmanaged apps in Edge for Business. Existing policies and enforcement remain unchanged.

For Intune administrators

Update Windows MDM-only enrollment procedures and user instructions before January 15, 2027; existing devices and other enrollment methods are unaffected. For CMG upgrades, check Azure capacity and vCPU quotas, install KB39169655 before September 30, 2027, and upgrade the Configuration Manager console afterward. Review Intune RBAC for the new device page, coordinate Purview and Intune administrators for the unmanaged Edge app workflow before November where applicable, and create or update a security baseline profile for Windows 11 version 26H2 because existing profiles do not update automatically.
