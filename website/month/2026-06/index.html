Apple’s iOS 18 and macOS 15 support floors top Intune’s June changes

June was mostly documentation maintenance: 680 of 698 records were updates, and many sampled diffs only normalized admin-center links, punctuation, or wording. The substantive exceptions were future Apple support-floor changes, a Microsoft 365 Apps policy-configuration move, newly documented Enterprise App Catalog auto-update scope, and a new read-only STIG assessment path. The Microsoft 365 Apps baseline page also says version 2512 replaces version 2306; the supplied evidence does not label these documentation additions as preview or general-availability launches.

  • Intune · App management
    iOS/iPadOS support requirement will rise to version 18

    This Message Center plan for change says Intune will require iOS/iPadOS 18 or later after Apple’s iOS/iPadOS 27 release later this year. Userless devices enrolled through ADE have different OS requirements, so device compatibility and Intune reports need separate review. This is a future support-floor notice, not an immediate retirement announcement.

  • Intune · Device enrollment
    macOS support will move to version 15 and later

    After Apple’s macOS Golden Gate 27 release later this year, Intune will support macOS 15 and later. Existing devices on macOS 14.x or below remain enrolled, but new enrollments on those versions will not be allowed. The notice supplies no exact enforcement date.

  • Intune · Device configuration
    Microsoft 365 Apps policy settings move out of Intune

    Starting with Intune’s June 2026 release, Microsoft 365 Apps policy settings will be configurable only in the Microsoft 365 Apps admin center, not the Intune admin center. Existing policies and functionality remain unchanged, making this a change to the administration path rather than policy behavior.

  • Enterprise App Management · App management
    Enterprise App Catalog guidance defines Required-only auto-update scope

    The updated Enterprise App Management article says Enterprise App Catalog apps can automatically update when auto-update is enabled and the app has a Required assignment. The scope is Windows 10 and Windows 11; apps assigned Available for enrolled devices retain the existing update workflow, and guided update supersedence remains an alternative. This is an added documentation description, not an explicit preview or general-availability announcement.

  • Intune · Device security
    New STIG baseline guidance is explicitly audit-only

    New Intune guidance documents a read-only Security Technical Implementation Guide audit baseline for Windows 10 and Windows 11. The listed Microsoft Windows 11 STIG SCAP Benchmark is version 2, Release 7, with 197 rules and a January 5, 2026 benchmark date. Intune assesses current configuration and provides per-setting and per-device reports through the admin center, Graph API, or CSV, with XCCDF compliance reporting; unlike other security baselines, it does not configure or enforce settings.

For Intune administrators

Use Intune inventory and reports to identify iOS/iPadOS devices that may fall below version 18 and macOS devices on 14.x or below; plan upgrades around Apple’s later-2026 releases, treating userless ADE devices separately. Update Microsoft 365 Apps runbooks to use the Microsoft 365 Apps admin center without recreating existing policies. Review Required Enterprise App Catalog assignments if auto-update is appropriate; Available assignments retain their existing workflow. DoD organizations can use the STIG baseline for assessment and reporting, but should not expect it to configure or enforce settings. Review Microsoft 365 Apps baseline version 2512 and its documented defaults before changing baseline plans.
