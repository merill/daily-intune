Month in brief

26H2 baseline adoption needs profile changes as Configuration Manager 2609 drops Server 2012 clients

October’s most consequential administrator impact centers on Windows 11 version 26H2 baseline guidance and the Configuration Manager 2609 transition. Intune guidance covers 26H2 Settings Catalog support, new settings, updated defaults, and revised guidance, while existing baseline profiles do not update automatically. Configuration Manager 2609 requires specific hierarchy-update planning, drops support for Windows Server 2012 client operating systems, and changes several security and approval behaviors. Endpoint Privilege Management guidance also documents controlled IPv4, IPv6, and DNS changes for standard users. Other updates document Remote Help availability in GCCH and clarify Android 15 factory-reset account re-entry; the remaining items are chiefly planning or reference clarifications.

  • Intune · General
    Windows 11 26H2 baseline adoption requires explicit profile changes

    Intune guidance now covers the Windows 11 version 26H2 security baseline and Settings Catalog support, including new settings, updated defaults, and revised guidance. Existing security baseline profiles do not update automatically; administrators must create a new profile or update an existing one to adopt the 26H2 baseline.

  • Configuration Manager · General
    Configuration Manager 2609 upgrades require a top-level service connection point

    The 2609 upgrade checklist specifies a top-level service connection point. After the parent site is updated, secondary sites require manual updating, making hierarchy sequencing part of the upgrade plan.

  • Configuration Manager · General
    Configuration Manager 2609 drops Windows Server 2012 client support

    Version 2609 no longer supports Windows Server 2012, Windows Server 2012 R2, or their Windows Storage Server editions as client operating systems. Affected devices must be identified and upgraded to a supported Windows Server version.

  • Configuration Manager · General
    Configuration Manager 2609 changes CMPivot, SQLCLR, CMG, and approval behavior

    The 2609 changes include CMPivot clients trusting its signing certificate, SQLCLR no longer requiring TRUSTWORTHY, automatic disabling of CMG storage shared-key access, and upgrade checks warning about automatic computer approval. The guidance also calls out planned removal of automatic approval for all computers.

  • Endpoint Privilege Management · Device security
    Endpoint Privilege Management documents controlled network-setting elevation

    The new EPM guidance describes policies that let standard Windows users change IPv4, IPv6, and DNS settings while requiring confirmation, business justification, Windows authentication, or both. Devices must have an EPM elevation settings policy enabled.

For Intune administrators

For Intune, create a new 26H2 baseline profile or update an existing one because profiles do not update automatically. Configuration Manager administrators should verify a top-level service connection point, plan manual secondary-site updates, identify unsupported Windows Server 2012, 2012 R2, and Windows Storage Server client editions, and review the documented CMPivot, SQLCLR, CMG, and computer-approval behavior changes. EPM administrators need an enabled elevation settings policy before delegating network-setting changes. GCCH support teams can use Remote Help for enrolled Android and Windows devices with role-based access controls and Microsoft Entra ID sign-in. For Android 15 reset workflows, a configured Google account email must be re-entered after the reset.
