Day in brief

Configuration Manager log guidance narrows modern-component scope and reshapes reference navigation

28 January was a Configuration Manager-only maintenance period: all 92 supplied changes were updates, with no new items, removals, or Message Center announcements. The evidence is dominated by metadata and ownership maintenance rather than feature releases. The substantive exceptions clarify log-file guidance and reorganize the Log Files reference page; neither indicates a product behavior change.

  • Configuration Manager · General
    Modern Configuration Manager components are excluded from the documented log settings

    The About Log Files page adds a note that the settings apply to native-code components, including most older site-server components, but don't apply to modern components such as SMS_MESSAGE_PROCESSING_ENGINE and SMS_ISVUPDATES_SYNCAGENT implemented in managed code. It also notes that these later component log names can exceed eight characters and contain underscores. This is documentation clarification, not evidence of changed logging behavior.

  • Configuration Manager · Endpoint analytics
    The Log Files reference navigation is reorganized

    The Log Files page replaces its prior table-of-contents structure with a Log file reference entry, adds a Packages and programs section, and changes visible section links from autogenerated #-style anchors to BKMK_* anchors. The change affects documentation navigation and linking, not Configuration Manager functionality.
