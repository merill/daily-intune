Day in brief

In-development Strict Tunnel Mode will block Android traffic outside Microsoft Tunnel

The substantive story is a planned Microsoft Tunnel traffic-enforcement mode for Android, alongside updated Recovery Lock rollout timing. Most other notable edits are documentation clarifications covering current admin-center paths, RBAC terminology, Platform SSO prerequisites, and Endpoint analytics navigation; the supplied evidence does not show a general-availability launch or changed remote-action semantics.

  • Intune · Device enrollment
    Microsoft Tunnel plans Strict Tunnel Mode for Android Enterprise and MAM

    The In Development entry says Microsoft Tunnel will support Strict Tunnel Mode for Android Enterprise devices enrolled through Android Management API and for unenrolled Android devices using Microsoft Tunnel for MAM. With an Always On VPN profile, the mode will force network traffic through the tunnel and block traffic if the VPN connection is unavailable; admins will be able to define app exclusions. It applies to personally owned and corporate-owned work profiles, corporate-owned fully managed devices, and unenro

  • Intune · Apple
    Recovery Lock guidance now targets mid-May rather than late April

    The macOS settings catalog guidance now says Recovery Lock is gradually rolling out and that full availability is expected by mid-May 2026, replacing the previous late-April expectation. The diff changes rollout timing guidance, not the setting’s documented behavior.

  • Intune · Apple
    Platform SSO guidance clarifies the single-policy setup sequence

    The macOS scenario guide says admins must configure Platform SSO first, create a Platform SSO settings catalog policy, and add scenario settings to that existing policy because only one SSO policy can be assigned to a group. This clarifies procedure and prerequisites rather than announcing a new Platform SSO capability.

  • Intune · Tenant administration
    Cleanup Rules documentation now names Intune Administrator

    The procedure now lists Intune Administrator and a custom role instead of Intune Service Administrator and a custom role. It also spells out the path as Devices > Organize devices > Device cleanup rules with direct admin-center links. The diff shows documentation terminology and navigation changes, not a confirmed backend RBAC change.

  • Intune · Endpoint analytics
    Endpoint analytics procedures adopt current Reports and Configuration paths

    The Configure page changes Reports > Analytics > Endpoint analytics to Reports, then under Analytics, Endpoint analytics, and changes Devices > Configuration profiles to Devices > Configuration. Direct links to those locations were added. This is an admin-center navigation clarification, with no evidence of a feature or permission change.
