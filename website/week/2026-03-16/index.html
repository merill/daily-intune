Week in brief

Opt-in scoped permissions preview changes Intune RBAC as cloud configuration guidance retires

The period’s consequential items are a security-sensitive RBAC preview, the deprecation of automatic Windows cloud-configuration deployment, and concrete platform updates. Intune’s service-release notes list macOS Recovery Lock as available and add Apple DDM Settings Catalog entries; Android Enterprise guidance records a direct LOB-app route for fully managed and dedicated devices; and Endpoint Analytics now accepts WinHTTP-proxied telemetry. Much of the remaining material is ordinary documentation maintenance—wording, navigation, formatting, endpoint-table cleanup, and corrected examples. One useful clarification is that most attack surface reduction profiles use Settings Catalog, while Application control remains template-based.

  • Intune · Tenant administration
    Scoped permissions becomes an opt-in public preview

    Preview / changed behavior: When an administrator has multiple role assignments with different scope tags that share a permission category, Intune’s default behavior merges permissions and can broaden access. The new Scoped permissions setting keeps each assignment’s permissions within its own scope-tag context. Microsoft recommends running the Permissions Assessment Report at Tenant administration > Roles > Settings first; enabling the setting is a one-time tenant action that cannot be undone.

  • Intune · Fundamentals
    Automatic Windows cloud configuration deployment is deprecated

    Retirement / deprecation: the Cloud Configuration article says the guided scenario for automatic deployment of Windows in cloud configuration is deprecated and being removed from the Intune admin center. It directs administrators to the Windows client cloud config setup guide for manual, step-by-step deployment.

  • Intune · Fundamentals
    macOS Recovery Lock is listed as available in service release 2603

    Availability: Recovery Lock lets administrators configure a recovery OS password for company-owned macOS devices, preventing recovery-mode boot, macOS reinstallation, and bypass of remote management. A Settings Catalog policy can enable the feature and configure password rotation; the Recovery Lock remote action can manually rotate the password.   • Intune · App management
    Android Enterprise guidance adds a direct-APK LOB deployment route

    Documentation clarification / supported deployment option: updated guidance states that required Android line-of-business apps can be uploaded as APK files directly to Intune and assigned as required on Android Enterprise fully managed and dedicated corporate-owned devices, without using Managed Google Play. The limitation is explicit: this path applies to those enrollment types.

  • Intune · App management
    WinHTTP proxy devices can now feed Endpoint Analytics and EPM

    Changed behavior: devices configured with system-level WinHTTP proxy settings can now send telemetry to Endpoint Analytics and Advanced Analytics, while Endpoint Privilege Management includes elevation-usage data from those devices. The release note says no administrator action is required; when the capabilities are enabled, data appears in the User Experience device view, Endpoint Analytics reports, and EPM.

For Intune administrators

RBAC owners should run the Permissions Assessment Report at Tenant administration > Roles > Settings before opting in to Scoped permissions; the change is one-time and cannot be undone. Windows cloud-configuration operators should use the manual step-by-step setup guide for new deployments because automatic guided deployment is deprecated and being removed. Mac administrators can evaluate Recovery Lock and the permission required to view its password. Android Enterprise administrators can assess direct APK deployment for required apps on fully managed and dedicated corporate-owned devices. No administrator action is required for the newly documented WinHTTP proxy telemetry support.
