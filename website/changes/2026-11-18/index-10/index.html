App management

Index

18 November 2026Doc update+9 / −9 lines

In brief

The deployment documentation now describes selecting Platform, Category, and App type for Android apps, including store, Managed Google Play, LOB, built-in, web, and system apps. It retains App type-only instructions for other platforms.

What Intune admins need to know

Administrators should use the updated selection sequence when following the documented steps to add Android apps.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
