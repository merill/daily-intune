Enable Tls 1 2 Server

4 November 2026Doc update+12 / −10 lines

In brief

The documentation now links to a built-in Azure Policy definition for configuring TLS 1.2 and updates wording, dates, links, and platform guidance. SQL Server, WSUS, and Windows Server support notes were also clarified.

What Intune admins need to know

Administrators configuring TLS 1.2 have a direct Azure portal policy reference and should review the updated prerequisites and support guidance.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
