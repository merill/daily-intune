Setup Automated Macos

30 October 2026Retirement+8 / −14 lines

In brief

Intune ended support for Setup Assistant (legacy) with the October 2026 (2610) service release. Existing profiles are automatically updated to Setup Assistant with modern authentication, which is now the only documented option.

What Intune admins need to know

Review enrollment guidance and profiles to ensure they use modern authentication; existing profiles update automatically.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.
