App management

Ref Settings Windows

18 November 2026Public preview+17 / −6 lines

In brief

The documentation now lists Windows App alongside Microsoft Edge as a supported app for Windows MAM app protection policies.

What Intune admins need to know

Administrators can include Windows App when reviewing Windows MAM support and policy scenarios for personal Windows devices.

This summary was assembled from the tracked documentation change. Verify important details in the full Microsoft Learn article.

Documentation change

View full page diffView on Microsoft Learn

The comparison below shows only the changed extract. Use the full-page view for complete context.

This article describes app protection policy (APP) settings for Windows. The policy settings that are described can be configured for an app protection policy on the Settings pane in the Intune admin center when you create a new policy.

You can enable protected MAM access to org data via Microsoft Edge and Windows App on personal Windows devices. This capability is known as Windows MAM and provides functionality using Intune Application Configuration Policies (ACP), Intune app protection policies, Windows Security Center client threat defense, and Application Protection Conditional Access. For Microsoft Edge, Windows MAM also supports Intune Application Configuration Policies (ACP). For more information about Windows MAM, see Data protection for Windows MAM, Create an MTD app protection policy for Windows, and Configure Microsoft Edge for Windows with Intune.

Important

Support for Windows App in Windows MAM app protection policy is currently in preview. Preview features aren't meant for production use and might have limited support. For more information about the Windows App on Windows public preview, including configuration requirements and supported scenarios, see Require local client device security compliance.

There are two categories of app protection policy settings for Windows:

  • Data protection
  • Health Checks

Supported apps

Windows MAM app protection policy settings for Windows support the following apps:

  • Microsoft Edge
  • Windows App (preview)

Important

Intune MAM on Windows supports unmanaged devices. If a device is already managed, then Intune MAM enrollment is blocked and app protection policies settings aren't applied. If a device becomes managed after MAM enrollment, app protection policies settings are no longer applied.

- Any destination and any source: Org users can paste data from and cut/copy data to any account, document, location, or application.
